# POSEIDON UAT geri bildirim

Bu depo yalnız UAT test geri bildirimi içindir; uygulama kodu burada değildir.

- Test ortamı: https://UAT_ALAN_ADI (giriş bilgisi size ayrıca iletilir)
- Yeni bildirim: **Issues → New issue → "Hata bildirimi" veya "Öneri"**
- Bir düzeltme yayına alındığında ilgili bildirim otomatik kapanır ve altına "UAT'ta yayında, sürüm …" yorumu düşer. Lütfen o sürümde tekrar deneyip sorun sürüyorsa bildirimi yeniden açın (Reopen) ve yorum yazın.
- Ortamdaki bütün veriler sentetiktir. Gerçek gemi/mürettebat/kişi verisi, parola veya kişisel veri içeren ekran görüntüsü paylaşmayın.
- UAT testleri pilot onayı, emniyet/mevzuat onayı veya yayın kararı yerine geçmez.
