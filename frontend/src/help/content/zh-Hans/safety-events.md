## 本页用途
“安全事件与未遂事件”页面让您快速报告船舶上的安全事件，并跟踪其后的人工步骤：分级、调查、独立审查、纠正和预防措施、核验、有效性和关闭。它回答的问题是：“发生了什么？由谁处理？措施是否真正有效？”这里不会自动决定严重程度、根本原因或关闭；每一项都是单独的人工记录。本页遵循发现项 → 措施 → 核验链，且**已关闭不等于有效**（13.03 §4）。

## 谁使用本页
- **Crew / OOW / 轮机员和船长：**报告未遂事件、事故、意外、疲劳、环境或网络事件（13.03 §2, §6）。
- **DPA / HSEQ：**作为安全桥梁，关注关键事件和逾期措施，并管理调查和措施有效性（13.03 §4）。
- 分级、调查、审查、身份读取、措施编写、核验和有效性审查是彼此独立的权限；每个用户只能看到自己拥有权限的部分。

## 开始之前
- 选择正确的船舶（**选择船舶**）。没有访问权限时，您会看到“您无权访问此船舶的安全事件。”
- 报告需要报告权限；读取列表需要读取权限。
- **保密**报告和**提交报告**需要网络连接。离线时您只能保存实名草稿，且只能在事先准备好的设备上进行。
- 时间以 UTC 输入。

## 操作步骤
1. 在**事件**列表中查看该船舶的事件。使用**仅我的报告**只查看您自己的报告。
2. 对于新记录，按**报告事件**。在**报告方式**中选择**实名**或**保密**。对于需要跟进的保密报告，请选择**给我一个私人跟进码**。
3. 填写**事件类型**、**何时发生？**、**作业**、**船上位置**、**摘要**、**发生了什么**、**是否采取了即时措施？**，并可选择填写**您估计的严重程度**。如果时间未知，请选择**未知**并填写**为什么时间未知？**。
4. 内容不完整时可以**保存草稿**。当**提交前仍需填写**为空时，按**提交报告**。未提交的草稿可以通过**撤回草稿**并附理由撤回。
5. 如果签发了跟进码，请立即私下保存**您的保密跟进码**中的代码，然后按**我已保存**。它只显示一次。之后，在**保密跟进**下将其输入为**跟进码**，并按**打开**阅读团队回复。
6. 分级人员在**初步分级**中附理由记录严重程度和**需要调查**，然后按**记录分类评估**，或使用**退回给报告人**退回。
7. 调查人员按**开启调查**，填写**促成因素**、**根本原因**、**屏障**和**不确定性**，然后按**保存调查**和**提交审查**。在**独立审查**中，由另一人选择**批准**、**退回**或**拒绝**。
8. 在**纠正和预防措施**中，使用**添加措施**并填写负责人、到期日期以及所针对的发现项。由负责人记录**报告完成**，另一人记录**核验**，第三人记录**评审有效性**。
9. 当**关闭阻碍项**为空时，由既不是报告人也不是调查编写人的审查人（具有审查权限）按**关闭事件**。在**消息**中，您可以以**仅团队**或**与报告人共享**的可见范围发送消息。

## 状态含义
- **草稿 / 已提交 / 已退回 / 已分级 / 调查中 / 措施跟踪 / 已关闭 / 已撤回：**事件的生命周期。
- **严重程度 — 未分级 / 未评估：**尚无人工分类。**报告人估计**仅为建议。**严重程度策略：未配置 – 仅人工分类**表示系统不会推导严重程度。
- **调查需求为 UNKNOWN：**尚未作出决定；它不表示“否”，并且会阻止关闭。
- **措施 — 未关闭 / 已完成 / 已核验：**已完成不等于已核验，已核验也不等于有效。
- **有效性 — 待处理 / 有效 / 无效 / 无定论 / 无措施 / 不可见：**有效性是针对每项措施的人工审查，与关闭是分开的。**无措施**并不表示有效。
- **未关闭的安全事件**摘要：**存在未关闭的高严重程度事件**、**需要审查**或**无未关闭的高严重程度事件**。在未配置严重性策略时，将显示**严重性策略未配置 – 需要审查**而不是该无问题状态，因为无法排除高严重程度事件。它只是警告；它不提供任何就绪决定。
- **保密（受保护）：**报告人身份保存在受限保管库中，不会向读者显示。
- **离线采集 / 等待同步 / 已保存到此设备。尚未发送。**排队不等于已发送。

## 不能做的事 / 注意
- 报告人不能对自己的报告进行分级。调查编写人、提交人或报告人不能进行独立审查。
- 只有措施负责人才能报告完成。负责人和完成人都不能核验；负责人、完成人和核验人都不能审查有效性。这些是由不同人员作出的独立记录。
- 根本原因是人工陈述；系统绝不会提出根本原因。
- 已提交的报告绝不能由其作者撤回或删除。
- 在保密报告中，身份只按需知原则打开，由拥有身份读取权限并选择**目的**的人打开；每次读取都会连同其目的被记录。匿名报告需要公共受理渠道，而该渠道尚未配置。
- 无定论的审查可以重复进行；有效和无效是最终结果；无效的措施需要新的后续措施。

## 出现问题时
- **服务器拒绝了命令：**补全其下方列出的缺失或阻碍项。
- **该记录在此期间已被更改。请重新加载并审阅后再试。**按**重新加载**。
- **结果未知（连接中断）。**使用**重试同一命令**；它不会被执行两次。
- **您无权执行此操作。**检查您的角色、船舶和对象上下文；必要时联系租户管理员（13.03 §10）。
- **设备密钥不可用**或**需要在线重新授权：**已采集的数据会被保留；在线时请重新授权。如遇应用程序错误，请附上关联 ID、界面、时间和操作步骤联系支持团队（13.03 §10）。
