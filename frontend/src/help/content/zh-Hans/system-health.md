## 本页用途
“系统健康状况”在一个界面上向管理员显示**服务观测**：API、审计写入器、同步、通知作业、文件服务和输入时效性。它回答的问题是：“对于所选船舶和本租户，观测到了哪些服务信号，哪些没有观测到？”配置情况和缺失的遥测数据都不能证明服务健康或船舶就绪。

## 谁使用本页
- **系统 / 租户管理员：**发现服务和同步问题，并以受控方式处理（13.03 §9）。
- **支持 / 工程：**在报告应用程序错误时审核观测结果（13.03 §10）。

## 开始之前
- 只有具备租户范围读取、操作历史读取和系统健康状况读取权限的用户才能看到本页。
- 在顶部上下文栏中检查是否选择了**正确的公司**。
- 观测按船舶请求；您必须先选择一艘船舶。

## 操作步骤
1. 在**船舶观测范围**中选择船舶。列表较长时，使用**上一页船舶** / **下一页船舶**。
2. 检查“读取时间”。
3. 在**服务存活状态**中，阅读进程启动时间和运行时长。
4. 在**API**和**审计写入器**卡片中，阅读请求、错误、已持久化和延迟数据。这些数据涵盖本租户自进程启动以来的情况。
5. 在**同步**中，查看已提交的结果、未解决的冲突和最近一次已提交的同步。
6. 在**通知作业**中，查看未结通知、已逾期的升级和评估作业状态。
7. 阅读**文件服务**和**输入时效性**卡片。
8. 在**试点指标**下，审核来自已登记试点客户端的观测结果。
9. 按**刷新观测**获取当前数据。

## 状态含义
- **未观测 / 不可用：**此信号没有观测结果。这并不表示“健康”或“没有问题”。
- **已配置 · 未探测：**文件服务看起来已配置，但尚未对存储或扫描器进行实时探测。
- **在计划内 / 运行中 / 已逾期 / 调度器未启用 / 运行已放弃（租约已过期）：**通知评估作业的状态。
- **未解决冲突：**等待人工解决的离线冲突。它们绝不会被自动合并。
- **当前 / 过时 / 未知 / 不可用：**输入时效性评估的计数。未知并不表示“当前”。
- **此快照已超过两分钟：**在依赖它之前请先刷新。

## 不能做的事 / 注意
- 本页为只读；不会对服务、船舶或记录执行任何操作。
- 通知记录仅存在于应用内；它们不能证明已送达，也不能证明任何安全决定。
- 服务存活状态只表明此 API 进程作出了响应；它不能证明其他服务正在运行。
- 试点指标是声明的且未经核验；它们不是验收声明。
- 不要直接在生产环境中修正数据；以受控方式发布配置变更（13.03 §9）。

## 出现问题时
- **此上下文无法访问健康状况：**检查您的角色和租户范围。
- **服务观测不可用：**不会推断为健康状态；稍后使用“刷新观测”。
- **存在未解决的冲突：**引导相关用户前往冲突中心（13.03 §10）。
- **应用程序错误：**附上关联 ID、界面、时间和操作步骤向支持/工程团队报告。
