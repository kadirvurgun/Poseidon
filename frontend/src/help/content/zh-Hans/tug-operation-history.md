## 本页用途
作业历史显示拖轮任务、执行、每日日志和证据的**只读历史**。它回答的问题是：“哪些任务以什么结果结束？执行是否已核验？是否有证据记录？哪些每日日志属于这些任务？”已取消和已中止的记录始终可见；不会删除任何内容，也不会重新标记。

## 谁使用本页
- **拖轮作业协调员 / 岸基运营：**跟踪已完成任务的证据完整性、事件和历史记录（13.03 §7）。
- **拖轮船长：**查看本拖轮过去的任务和执行时间线（13.03 §3）。

## 开始之前
- 从**拖轮作业**打开拖轮；未选择拖轮时，本页显示“请选择一艘拖轮以继续。”
- 拖轮读取权限即可；本页不更改任何数据。
- 历史从服务器读取；离线时无法刷新。

## 操作步骤
1. 在**筛选条件**中，可选择设置**拖轮 ID**、**起始(UTC 日期)**、**截止(UTC 日期)**和**结果**，然后按**应用筛选**。日期范围最多 400 天。
2. 在表格的每一行中，阅读**任务**（任务编号、被协助船舶、任务类型、计划和简报状态）、**活动时间**、**结果**和**证据**。
3. 在**执行**中，查看每次执行的状态、核验状态、持续时间、船长记录和证据条目数量；使用**打开执行时间线**进入执行控制台。
4. 使用**每日日志**中的链接打开相关日志。“日志未关联”的注释表示该日志没有关联此次执行。
5. 使用**加载更多**查看较早的记录。**读取时间**显示数据的读取时间。

## 状态含义
- **未开始 / 进行中 / 已完成(已记录) / 已中止 / 已取消 / 混合：**任务的总体结果。已完成(已记录)并不表示任务已核验。
- **已核验，证据已记录 / 已核验，无证据条目 / 核验被拒绝 / 证据未核验 / 未知：**证据和核验状态。
- **核验待定 / 已核验 / 核验被拒绝：**单次执行的核验状态。
- **无：**此任务不存在关联记录。这并不表示不需要记录。

## 不能做的事 / 注意
- 本页不编辑、不删除、也不核验任何记录。
- 不会静默删除：已取消的任务以及已中止或被拒绝的执行都保留在历史中。
- 已完成 ≠ 已核验：核验是另一人的记录。
- 显示的数据是**读取时间**时的状态；离线时不会刷新。

## 出现问题时
- **出现“筛选条件无效”消息：**检查拖轮 ID 是否为 UUID，以及日期范围是否超过 400 天。
- **出现“无法加载历史。”消息：**检查您的网络连接并按**重试**。
- **“您无权访问此拖轮范围。”：**检查您的角色和拖轮上下文；必要时联系您的租户管理员（13.03 §10）。
- **记录无法核验：**在执行时间线中检查证据引用及其来源；联系核验人（13.03 §10）。
