## 本页用途
“试点计划”页面将一艘船舶（以及可选的一艘拖轮）的试点周次、每周的检查项、试点问题、每日反馈和价值报告集中在一处。它回答的问题是：“每个试点周次的检查项是否都已由真实记录满足？测量值相对于基线有何变化？”顶部的提示适用：“软件不能完成试点。只有当您将检查项链接到经服务器核验的真实记录时，该检查项才算满足；缺失的基线保持未知；只有被任命的产品负责人才能关闭周次或记录计划决定。”

## 谁使用本页
- **产品负责人：**关闭周次并记录计划决定（继续、修复、停止、扩大）。这需要当前的产品负责人任命。
- **试点团队：**将记录链接到检查项，报告问题，记录反馈和测量。
- **分诊负责人：**对问题进行分诊并解决。
- 13.03 没有为本页定义单独的角色；适用租户管理原则（13.03 §9）。

## 开始之前
- 查看需要租户范围读取和试点计划读取权限。创建计划、记录、分诊和决定各自需要单独的权限；关闭周次和作出决定还需要产品负责人任命。
- 您链接的记录（例如证书、船员或工单记录）必须已在其各自的页面上存在。
- 在反馈中切勿输入姓名、电子邮件地址、电话或证件号码；只使用化名和角色。
- 记录需要实时连接。

## 操作步骤
1. 从**试点计划**中打开一个计划。对于新计划，请在**创建试点计划**中填写**计划名称**、**船舶**、**拖轮（可选）**、**第 1 周开始日期**和**日历时区（IANA）**，然后按**记录**。
2. 在每个**周**部分中，审核**检查项**、**标准（来源）**、**范围**、**状态**和**已链接记录**列。
3. 要满足某个检查项，请在**链接记录**中输入**检查项**、**记录类型**和**记录标识**，然后按**链接记录**。写下**撤回原因**后，使用**撤回链接**移除错误的链接。
4. 在**试点问题**中，使用**报告问题**输入范围、**类别**、严重程度和**问题摘要**。分诊负责人使用**初步分级**并填写**分诊备注**，然后解决问题。
5. 在**每日反馈**中，使用**记录反馈**输入**摘要**和**感受**。
6. 在**价值报告**中，使用**记录测量**输入**指标**、**阶段**（基线或试点期间）、**数值**、**样本数量**、**期间起**、**期间止**、**证据参考**和**方法与样本**。
7. 如果您是产品负责人，请在**关闭本周**中记录结果和理由。计划结束时，在**记录计划决定**中填写决定、**任命**和**理由**，然后按**记录**。

## 状态含义
- **已链接并验证：**一条经服务器核验的真实记录已链接到该检查项。**链接已失效**和**缺失**的检查项未被满足。
- **需要完成：**链接的记录必须处于已完成状态。“审计轨迹证明有人编写了该记录；它不能证明记录或流程已完成。”
- **可供人工关闭 / 未就绪：**对该周的建议；只有产品负责人才能将其关闭为**已接受**或**未接受**。
- **当日已分诊 / 分诊延迟 / 今日应分诊 / 已逾期：**P0 问题相对于计划日历日的分诊时间。对于**来源未规定当日目标**的问题，系统不会自行设定截止时间。
- **已测量 / 未知：**当基线值或试点值缺失时，报告保持**未知**；它绝不会被计为零或改善。**不可比较**的值不会进行比较。
- **遥测（已申报，未验证）：**声明的遥测值。
- **符合扩大条件；待人工决定 / 建议修复：**计划建议，不是决定。

## 不能做的事 / 注意
- “只有当每个检查项都已核验且没有未关闭、待处理或延迟的 P0 分诊时，才可能为已接受。”
- “只有当每个周次都已接受，且数值、UAT、缺陷和 P0 都没有问题时，才可能扩大。”
- 如果某个周次或决定所依据的证据（链接、反馈、测量）是您编写的，您不能关闭该周次或记录该决定。
- 虚构数据计划不能记录周次关闭或决定。
- 系统绝不会完成试点，绝不会关闭周次，也绝不会伪造决定或签署。

## 出现问题时
- **您当前没有产品负责人任命；周关闭和决定为只读。**请联系租户管理员获取任命（13.03 §10）。
- **在运维人员配置保留策略之前，无法收集反馈。**请系统管理员配置保留策略。
- **记录已变更或已被使用。请重新加载。**使用**重新加载**打开当前状态。
- **结果不确定。重试将发送相同命令。**使用**重试**安全地重新发送同一命令。
- **被规则拒绝。**例如，链接的记录可能不存在、超出范围或尚未完成。
- **不允许。**此周次关闭或决定所依据的链接、反馈或测量是您编写的；必须由另一人记录。
- 尚未开始的周次不能关闭（显示为“记录已变更或已被使用。请重新加载。”）。
- **您无权访问这些记录。**检查您的角色和租户范围（13.03 §10）。
