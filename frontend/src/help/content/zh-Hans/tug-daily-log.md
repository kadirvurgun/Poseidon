## 本页用途
拖轮日志针对一个日期和值班记录**任务、主机运行计数器、燃油和缺陷**，并将其与当天的拖带作业执行进行**核对**。它回答的问题是：“这一天/这个值班完成了多少个任务？计数器小时数是否与执行时间相符？使用了多少燃油？报告了哪些缺陷？”核对结果仅为建议；船长审核是单独的人工记录。

## 谁使用本页
- **船员 / 值班人员：**实时并按顺序保持值班记录（13.03 §6）。
- **拖轮船长 / 船长：**审核已提交的日志，并核验或退回（13.03 §3）。

## 开始之前
- 从**拖轮作业**打开拖轮。
- 创建和编辑日志需要拖轮写入权限。
- 审核需要服务器中已记录的该拖轮**任命**（拖轮船长或船长）。编写或提交日志的人不能审核它。

## 操作步骤
1. 从列表中打开现有日志，或选择**日志日期**和**值班**后按**创建日志**。
2. 输入**时区 (IANA)**。
3. 在**主机运行时间计数器**中，为每个**计数器**输入**起始读数**、**结束读数**，必要时输入**归零或溢出翻转证据**。
4. 在**燃油消耗**中，输入数值、单位和**燃油来源参考**。
5. 在**当日拖带作业执行**中勾选属于此日志的执行；填写关联的缺陷标识和**每日摘要**（摘要至少 20 个字符）。
6. 按**保存**。在**核对**行上，检查已完成的任务、执行小时数、计数器小时数和已报告的缺陷。
7. 当**阻碍项**列表为空时，按**提交船长审核**。
8. 作为船长，选择您的**任命**，写下理由，然后按**船长：核验日志**或**船长：退回日志**。

## 状态含义
- **草稿 / 已提交 / 已退回 / 已核验：**日志状态。
- **船长审核 — 待处理 / 关注 / 已审核：**待处理 = 等待审核；关注 = 已退回，或在核对结果不是“已核对”时提交；已审核 = 已由船长核验。已提交的日志不是已核验的日志。
- **已核对 / 需要审查 / 不完整：**建议性的比较结果。原因代码列在其下方。
- **未结束区间：**某次执行仍在进行中；执行小时数尚未最终确定。
- **安全事件 — 未知：**本页不统计安全事件；不会得出“没有事件”的结论。
- **已同步 / 等待同步 / 冲突 / 失败：**同步状态。等待同步表示更改尚未到达服务器。

## 不能做的事 / 注意
- 编写日志或将其提交船长审核的人不能核验它。
- 核对结果不是批准；由船长进行审核。
- 完成记录与核验记录不是同一个操作（13.03 §1）。
- 离线时，一项未保存的更改会保留在此页面的内存中，并在网络连接恢复时以其原始键发送；请保持页面打开。提交和审核在线进行。
- 如果出现冲突，不要假定您自己的记录会自动胜出（13.03 §6）。

## 出现问题时
- **出现“服务器列出了缺失或阻碍的条目。”消息：**清除**阻碍项**中的代码。
- **出现“记录已更改或命令冲突。”消息：**使用**重新加载最新版本**审核当前日志；保留的本地更改会被丢弃。
- **出现“结果未知。”消息：****重试**会再次发送完全相同的命令。
- **冲突：**保留在此页面上的更改绝不会被合并；请使用**重新加载最新版本**。在**拖轮离线作业**中采集且发生冲突的每日条目在该处解决；它们也会列在**重大冲突中心**中（13.03 §10）。
