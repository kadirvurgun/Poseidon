## 本页用途
“高风险作业”页面在一个**只读**列表中显示船队作业（如动火作业、封闭处所、高处作业、电气隔离、关键维护、拖带和加油作业）的异常。它回答的问题是：“哪项高风险作业在风险、许可、关键屏障、船员或设备方面存在未决问题？由谁负责下一步措施？”每个维度单独显示；没有汇总评分。操作会打开所属记录；本页不更改任何记录，也不作出开始作业的决定（13.03 §4）。

## 谁使用本页
- **DPA / HSEQ：**作为风险治理的一部分，关注整个船队的高风险作业异常（13.03 §4）。
- **船长和拖轮船长：**查看本船高风险作业的阻碍项，并进入所属记录。开始或停止作业的决定始终由他们作出（13.03 §2, §3）。

## 开始之前
- 查看需要风险读取和高风险作业读取权限。没有这些权限时您会看到“您无权访问高风险作业视图。”
- 列表只涵盖您范围内的船队和船舶。
- 离线时显示的列表可能已过期。

## 操作步骤
1. 选择**船队**、**船舶**和**作业类型**筛选条件。**全部**会移除筛选条件。
2. 在表格中分别阅读每项作业的**风险**、**许可**、**关键屏障**、**船员**和**设备**状态。**关键阻断项**和**待审核项**标记显示数量。
3. 使用**下一步措施**和**责任人 / 到期**列查看谁需要做什么。
4. 要查看某一行为何处于该状态，请按**原因**。会打开一个包含**维度**、**状态**和**理由**的表格；使用**隐藏**关闭。
5. 要进行任何更改，请通过作业链接或**打开记录**；操作在所属记录自己的页面上进行。
6. 使用**上一页**和**下一页**翻页。**评估时间**和**来源覆盖**显示列表是何时、根据哪些来源计算的。

## 状态含义
- **就绪 / 有条件 / 关注 / 未就绪 / 已阻止：**该维度在其来源中的状态。某个维度为就绪并不表示作业可以开始；决定始终由获授权人员作出。
- **需要审查：**需要有人审核。
- **未知：**来源不可用；它绝不是就绪。POSEIDON 目前还没有作业许可来源，因此**许可**列始终显示**未知**。
- **正常 / 降级 / 故障：**关键屏障的状态。
- **未分类：**作业类型未知或其关键性尚未确定；它不会被排除在列表之外。
- **等待来源 / 解决停止或争议 / 更新已过期项 / 完成必需项 / 重新评估 / 打开负责人记录：**下一步措施，按固定的优先顺序显示。
- **到期未确定 / 未计划：**到期日期或计划开始时间未知。

## 不能做的事 / 注意
- 本页为只读；它不更改、不批准、也不许可任何事项。
- 没有汇总评分；存在关键阻断项的作业始终排在最前面，其他维度正常也绝不会掩盖它。
- 不要把**未知**理解为就绪。历史上的有效许可绝不是当前有效的许可。
- 开始或停止作业的决定始终由船长或拖轮船长作出。

## 出现问题时
- **服务不可用。请重试。**按**重试**。
- **您已离线。显示的列表可能已过期。**联网后按**重新加载**。
- 如果某个状态看起来出乎意料，请打开**原因**表格，并询问记录负责人或控制负责人（13.03 §10）。
- 如果没有访问权限，请检查您的角色和船舶上下文；必要时联系租户管理员（13.03 §10）。
