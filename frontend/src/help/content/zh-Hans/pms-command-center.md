## 本页用途
PMS 指挥中心在一个界面上汇集所选船舶的维护**异常**。它回答的问题是：“这艘船是否有逾期关键作业、未结工单、缺陷警报或关键备件缺口？原因是什么？”本页是建议性的异常视图；它不是适航、就绪或安全决定。正常的条目不会列出，只会计数。

## 谁使用本页
- **轮机长 / 技术主管：**跟踪逾期作业、未结工单、缺陷警报和关键备件缺口（13.03 §5）。
- **船长：**查看 PMS 和缺陷记录对作业限制的影响（13.03 §2）。

## 开始之前
- 您需要设备读取权限（`equipment.read`）才能查看本页。
- 每个部分取决于其所属模块的读取权限。例如，没有缺陷读取权限时，**状态警报**部分保持为“需要访问权限：未显示”。
- 请先选择船舶。未选择船舶时，本页只显示**请选择船舶。**列表。

## 操作步骤
1. 从列表中选择船舶。如果您的范围内没有船舶，本页会显示“您的范围内没有船舶。”
2. 阅读顶部的**异常摘要**标记和**上次刷新**时间。
3. 审核各部分：**逾期关键作业**、**到期、逾期及待复核作业**、**未结工单**、**状态警报**和**关键备件缺口**。
4. 打开某一条目的**原因**，查看记录的原因代码以及（如有）**观察于**时间。
5. 使用**打开来源记录**进入来源。缺陷条目会打开[缺陷与临时措施](/app/defects)，工单条目会打开[工单中心](/app/work-order-center)。
6. 按**刷新**重新读取数据。

## 状态含义
- **已阻止 / 需要审查 / 关注：**异常摘要的状态。详情见各部分的条目。
- **无未结异常（建议性）：**已读取的来源没有返回未结异常。这不是就绪或适航结果。
- **关键 / 关注 / 需要审查：**条目的严重程度。
- **来源不可用：未知，而非零：**无法读取该部分的来源。未知不等于“零”、“没有问题”或“就绪”。
- **需要访问权限：未显示：**您没有此部分的权限；既不显示内容，也不显示数量。
- **此来源无异常：**已读取该部分，未返回异常。正常条目的数量单独显示。
- **数据过时 / 时效性未知：**条目背后的读数不是最新的，或其时效性未知。

## 不能做的事 / 注意
- 本页不更改任何记录；它只读取。工单、缺陷和备件在各自的页面上处理。
- 本页绝不会宣布船舶“就绪”或“安全”。离港决定属于船长（13.03 §2）。
- 缺陷只有通过人工关闭记录才算关闭，并且只针对被关闭的声明修订版本。如果声明之后发生变更，该条目会回到审核状态。
- 离线时显示的数据可能是旧的，且**刷新**不可用。

## 出现问题时
- **无法加载记录：**检查您的网络连接并使用**重新加载**。
- **您没有此操作或记录的服务器权限：**检查您的角色和船舶上下文；必要时联系您的租户管理员（13.03 §10）。
- **意外的异常：**打开**原因**，并与责任负责人或领域专家一起审核来源记录（13.03 §10）。
- **应用程序错误：**向支持团队报告关联 ID、界面、时间和操作步骤（13.03 §10）。
