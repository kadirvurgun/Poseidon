## 本页用途
坞修计划保存所选船舶的**坞修工程包**（项目、船厂、计划日期和范围项）。它回答的问题是：“每个坞修范围项关联到哪个工单、缺陷、证书或检验检查清单？这些关联是否为当前版本？”范围与这些记录相关联（13.03 §5）。**关联就绪度**仅表示关联的完整性；它不是船级或船旗检验结果，也不是适航声明。

## 谁使用本页
- **技术主管：**准备坞修工程包，将范围关联到记录，进行计划并完成（13.03 §5）。
- **轮机长：**跟踪范围与缺陷和工单记录的关联情况，并在有权限时核验他人完成的工程包（13.03 §5）。

## 开始之前
- 选择正确的船舶。如果未选择船舶，本页会显示**请从工作区选择一艘船舶以继续。**
- 您需要坞修读取权限才能查看工程包。创建、编辑和更改状态需要写入权限；核验需要核验权限。
- 准备好您要关联的工单、缺陷、证书和检验检查清单记录的标识和修订版本。

## 操作步骤
1. 从列表中打开一个工程包，或使用**创建坞修工程包**创建一个空草稿。
2. 填写**坞修项目**、**船厂**、**计划开始**和**计划完成**。
3. 使用**添加范围项**添加条目；输入**范围项**类型、**标题**、**工作包**、**船级要求**、**法定要求**和**优先级**。
4. 在每个条目上，使用**添加关联**并输入**记录类型**、**记录标识**和**固定修订版本**。
5. 为完成工作，在**完成证据**下使用**添加**添加证据引用。然后按**保存**。
6. 检查**计划阻碍项**或**完成阻碍项**列表。在**更改状态**下，选择一个**操作**（**计划**、**退回草稿**、**开始坞修**、**完成坞修**、**取消工程包**）并确认。取消需要备注。只提供对当前状态有效的操作；工程包只有在草稿或已计划状态时才能取消。
7. 对于不是由您完成的已完成工程包，写下至少 10 个字符的**理由**，然后使用**核验记录**或**驳回核验**。
8. 在**时间线**中跟踪计划日期、实际日期和每个修订版本。

## 状态含义
- **草稿 / 已计划 / 进行中 / 已完成 / 已核验 / 已取消：**工程包的生命周期。已完成和已核验不是一回事。
- **关联为当前版本 / 关注 / 需要审查 / 不完整：**关联就绪度。即使关联为当前版本，这也不是检验结果。
- **已关联 / 未关联 / 已逾期 / 需要审查：**范围项的关联状态（当任一关联为过时或不可用时为需要审查）。
- **当前 / 过时 / 不可用：**关联记录与其固定修订版本的比较。请审核过时的关联，并使用**重新固定到**将其固定到新的修订版本。
- **未知 / 未设置：**未输入优先级。未知不等于“普通”或“低”。

## 不能做的事 / 注意
- 本页不判定坞修是安全的，也不判定船舶适航。
- 您不能核验自己完成的工程包。驳回核验会使工程包回到**进行中**。
- 成本、币种、供应商和预算只是外部引用；此处不进行汇总、批准或订购。
- 已完成、已核验或已取消的工程包不能编辑。
- 离线时不会发送命令。

## 出现问题时
- **服务器列出了缺失或阻碍的条目：**解决阻碍项列表后再试一次。
- **记录已更改或命令冲突：**使用**重新加载最新版本**并审核。
- **结果未知：****重试**会再次发送完全相同的命令。
- **您无权访问此记录：**检查您的角色和船舶上下文；必要时联系您的租户管理员（13.03 §10）。
- **您无法读取以下关联记录类型：**与记录负责人或您的租户管理员确认权限。
