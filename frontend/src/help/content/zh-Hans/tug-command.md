## 本页用途
本页在菜单中显示为**拖轮指挥**，显示所选拖轮的**来源背景**。它回答的问题是：“这艘拖轮记录了哪些角色、类型、系柱拖力（BP）和设备声明？它们来自哪里，有多新？”本页只显示声明及其来源；它不提供作业就绪、资格、许可或安全批准。顶部的标记也这样说明：“来源声明 · 作业就绪情况未知”。

## 谁使用本页
- **拖轮船长：**在开始工作前确认本拖轮的角色、BP 和设备背景（13.03 §3）。
- **拖轮作业协调员 / 岸基运营：**在进入任务看板和任务受理之前，确保处于正确的拖轮上下文中（13.03 §7）。
- **船员：**查看自己的角色视图以及向其开放的船舶模式界面（13.03 §6）。

## 开始之前
- 您需要拖轮模式和拖轮读取权限。没有这些权限时，本页显示“访问不可用。”
- 如果未选择上下文，本页会在**选择拖轮**下列出获授权的拖轮；打开其中一艘。
- 设备列表还需要设备读取权限；没有该权限时，设备来源显示为“不可用或未授予”。

## 操作步骤
1. 从**选择拖轮**列表中打开拖轮。标题下方的**拖轮背景**行显示拖轮代码、名称和模式。
2. 在**角色（服务器分配）**和**拖轮模式菜单视图**中，阅读服务器为您分配的角色和菜单视图。
3. 在**模式可见性**中，查看船舶模式界面是否开放。**船舶模式页面**部分只链接到授予您的界面。
4. 从**拖轮类型**、**类型来源 / 修订版**和**类型来源观测 / 策略**中检查类型来自哪个来源和修订版本。
5. 阅读**档案 BP（未经核验）**、**BP 来源 / 版本 / 溯源信息**和**BP 时效性 / 观测**。这是声明值，不是测量值。
6. 在**设备背景**中，查看设备声明、其级别、修订版本和溯源信息。
7. 使用页面标签进入**任务看板**或（有写入权限时）**任务受理**，或（有写入权限时）按**新建请求**。

## 状态含义
- **未知 — 无角色分配：**服务器中没有您在这艘拖轮上的角色分配。这不是“没有角色，也没有问题”；需要管理员进行分配。
- **角色标签不可用 / 菜单视图不可用：**目前无法读取来源。缺失的信息不会被视为空。
- **未为拖轮模式配置视图：**在此模式下没有为您定义菜单视图。
- **在拖轮模式下隐藏。需要跨模式角色。：**船舶模式界面需要明确授权的跨模式角色。
- **档案 BP（未经核验）：**声明的系柱拖力。它不是经核验的试验结果。
- **未返回设备声明。经核验的作业适用性仍未知。：**空列表绝不表示设备适用。
- **未知 / 不可用：**来源值缺失或无法读取。未知绝不能代替“就绪”或“否”。

## 不能做的事 / 注意
- 本页不编辑任何字段，也不产生任何就绪结果。作业决定和安全权限始终属于船上的拖轮船长（13.03 §3）。
- 岸基指派提议绝不能推翻拖轮船长在船上的安全决定（13.03 §7）。
- 即使有声明的跨模式权限，每个船舶模式界面仍需要其自身的服务器授权。
- 离线时不显示当前的档案来源；请重新连接以重新检查访问权限和来源版本。

## 出现问题时
- **访问不可用：**检查您的角色、拖轮和对象上下文；必要时联系您的租户管理员（13.03 §10）。
- **出现“必须检查当前身份和船舶访问权限”警报：**按**重新检查访问权限**。
- **数据不可用：**检查您的网络连接并按**重试**。
- **意外的 BP 或设备值：**记下来源和版本字段，并与来源负责人一起审核；如果记录无法核验，请检查其证据和溯源信息（13.03 §10）。
