## 本页用途
数据可信中心显示所选船舶的控制、证据和船舶档案字段的**数据质量信号**。它回答的问题是：“这艘船上哪些记录缺失、过时、相互冲突、未经核验或孤立？是哪些来源和时效性信息这样表明的？”可信信号不是对底层记录的核验。本页绝不会把任何内容标记为就绪。

## 谁使用本页
- **法规 / 保证用户：**避免在要求 → 控制 → 证据 → 核验链中遗留孤立或不完整的记录（13.03 §8）。
- **DPA：**跟踪证据和核验缺口（13.03 §4）。
- **技术主管 / 船长：**查看使就绪评估保持在需要审查状态的信号（13.03 §2, §5）。

## 开始之前
- 在顶部上下文栏中检查是否选择了**正确的公司**（13.03 §1）。
- 本页需要同时具备控制、证据、文件、适用性和租户法规草稿读取权限，并具有租户范围的读取范围。
- 如果未选择船舶，本页会先显示“请选择船舶”列表。

## 操作步骤
1. 从“请选择船舶”列表中选择船舶。
2. 在**摘要**中，阅读总体状态（“需要审查”或“无重要信号”）以及**各信号对象数**。
3. 在**控制与证据**表中，检查每个对象的“来源 / 出处”、“时效性”、“核验”和“信号”列。
4. 记下信号标记旁的原因代码，并在记录自己的页面上审核该记录。
5. 在**船舶档案字段**表中查看档案字段的信号。
6. 使用**上一页** / **下一页**查看其他对象。
7. 如果出现“这些信号可能已过期。”，请按**重新加载**。

## 状态含义
- **缺失 / 过时 / 冲突 / 未经核验 / 孤立：**对象上的信号类型。信号是质量标记；它不能证明记录正确或错误。
- **无信号：**在此对象上未发现信号。这并不表示记录已核验。
- **需要审查：**存在重要信号。存在重要信号时，就绪状态保持为需要审查。
- **无重要信号：**这不是就绪声明。
- **已人工验证：**获授权人员已核验该证据。这来自证据自身的记录；本中心不核验任何内容。
- **未核验 / 核验已过期 / 核验被拒绝：**证据的核验状态。
- **不适用于控制：**显示在控制行上；核验状态针对的是证据行。
- **观测时间未知 / 无时效性策略 / 日期在未来：**无法确定时效性，或日期在未来。这些都不表示“当前有效”。

## 不能做的事 / 注意
- 不能在本页更正、核验或关闭记录；这些操作由获授权人员在记录自己的页面上进行。
- 如果只评估了前面的部分对象，摘要保持为需要审查。
- 您无法读取的对象会被计数但不显示，此时摘要保持为需要审查。您看不到的记录并不表示不存在问题。
- 离线时无法刷新数据可信信号。

## 出现问题时
- **您无权读取数据可信信号：**检查您的角色和船舶上下文；必要时联系您的租户管理员（13.03 §10）。
- **记录无法核验：**检查证据及其出处；向获授权的核验人提出。
- **意外的信号：**向控制负责人或领域专家提出该原因代码。
- **数据可信信号不可用：**使用“重试”；如果问题持续，请附上截图、时间和您的操作步骤向支持团队报告。
