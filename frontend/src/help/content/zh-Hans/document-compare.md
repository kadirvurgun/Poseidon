## 本页用途
本页针对所选船舶，**以只读方式并排显示受控文件的两个修订版**。它回答的问题是：“这两个修订版在文件和元数据层面有什么不同？各自的发布、核验和保管历史是什么？”本页显示差异；它不批准、不发布，也不评判变更。它不会使某个修订版生效，也不会使其取代较早的修订版。证据原件绝不会被静默更改；当新修订版取代较早的修订版时，较早修订版的发布状态变为“已取代”，该事件会出现在其保管历史中（13.03 §1）。

## 谁使用本页
- **船长 / 轮机长 / 船员：**将生效的修订版与上一个修订版进行比较，并记录阅读确认（13.03 §2, §5, §6）。
- **DPA / 法规与保证用户：**审核修订历史和核验记录（13.03 §4, §8）。

## 开始之前
- 如果未选择船舶，本页会显示**请选择您权限范围内的船舶。**并列出船舶。请选择正确的船舶。
- 您需要文件读取权限才能查看本页。受限内容和 ISPS 受限文件还需要各自的权限。
- 加载内容和记录确认只能在线进行。

## 操作步骤
1. 从**受控文件**列表中打开一份文件。分类和**ISPS 受限**标签显示在该行上。
2. 在**选择两个修订版**下，选择**左侧（基准）**和**右侧（审阅）**修订版。本页首先在右侧建议最新修订版，在左侧建议其前一个修订版。
3. 按**比较**。使用**交换左右**进行互换。
4. 阅读字节说明和**元数据比较**表：**文件类型**、**大小（字节）**、**内容 SHA-256**、**接收**、**发布**、**核验**以及时间字段。
5. 审核每一侧的**审批与保管历史**。
6. 要查看内容，请按**加载内容（访问将被记录）**。内容会带有署名水印显示。
7. 在**加载内容**之后，如果您已阅读生效的修订版，请勾选**我已阅读此修订版并能够访问其内容。**并按**记录阅读确认**。

## 状态含义
- **未发布 / 已生效 / 已取代：**修订版的发布状态。未生效的修订版显示**未在运行中生效**。
- **未核验 / 核验为有效 / 核验为无效 / 核验无定论：**修订版的核验记录。未核验并不表示“有效”。
- **相同 / 已更改 / 不可比较：**元数据行的结果。不可比较并不表示“相同”。
- **字节完全相同的文件：**仅表示字节相同；这不是内容审核。
- **文件在字节层面存在差异：**哪条规则发生了变化及其重要性，需要由人审核。
- **您的角色无权查看内容；仅显示元数据。**此角色无法打开内容。

## 不能做的事 / 注意
- 您不能在本页发布、批准、使文件生效或取代文件。
- 本页不会自动解释内容差异；由获授权人员判断其重要性。
- 确认只针对生效的修订版记录，每人每个修订版一次。它不是批准，也不是核验。
- 打印的副本不受控。内容不会被缓存，也不会离线保存。
- 离线时比较结果已过时，且无法加载新内容。

## 出现问题时
- **您无法使用此文件：**检查您的船舶上下文和权限；必要时联系您的租户管理员（13.03 §10）。
- **您没有执行此操作的权限：**检查您的角色和船舶上下文（13.03 §10）。
- **记录在此期间已更改：**使用**重新加载**打开最新版本。
- **某个修订版无法核验：**检查证据和溯源历史；与获授权的核验人沟通（13.03 §10）。
- **请求失败：**将界面、时间和操作步骤发送给支持团队（13.03 §10）。
