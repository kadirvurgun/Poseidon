## 本页用途
“用户与权限”页面管理您的工作区中的**成员资格**。它回答的问题是：“这个人可以看到什么、做什么，以及在哪些船舶上？”账户本身（用户名、密码、MFA）存在于中央身份提供方（IdP）中，而不在 POSEIDON 中。本页将该账户**邀请**为成员，并授予角色包、权限和船舶范围（13.03 §9）。新成员是被邀请的：在本人登录并接受邀请之前，邀请不授予任何权限。

## 谁使用本页
- **租户管理员：**按最小权限原则分配用户、角色、船舶和对象范围，邀请新成员，并管理委托和暂停（13.03 §9）。
- 其他具有成员资格读取权限的用户可以查看列表，但不能更改。
- **被邀请的人**只打开邀请链接；他们绝不会看到本页。

## 开始之前
- 查看需要成员资格读取权限；更改需要成员资格管理权限以及租户范围的管理权限。只有读取权限时，您会看到“您可以查看但不能更改成员资格。”
- 此人需要在身份提供方中有一个账户。**Expected IdP subject (optional)**会将邀请限制为该账户；没有填写时，任何使用该链接登录的人都可以接受邀请。
- 请规划一个可信的渠道来移交邀请链接（例如贵组织自己的消息系统）。POSEIDON 不发送电子邮件。
- 您只能授予自己拥有的权限。您自己的成员资格由另一位管理员编辑。
- 成员资格管理需要实时的服务器连接；离线时不能进行任何更改。

## 操作步骤
1. 在**Members**列表中查看成员。按**状态**（例如**Invited**）和**Role bundle**筛选，然后按**Apply**。要搜索，请输入成员资格或账户 ID 前缀或确切的 IdP subject，然后按**搜索**。
2. 使用**打开**打开一个成员。审核**Effective permissions**、**船舶范围**、**Invitation**、**Grant history**和**Delegations**。
3. 要邀请成员，请按**Add member**。检查**IdP issuer**，可选择输入**Expected IdP subject (optional)**，选择至少一个**Role bundle**，必要时添加**Individual permissions**，并设置范围（租户范围或至少一艘船舶）。然后按**Create membership**。
4. 该成员以**Invited**状态打开，并显示**Invitation link**。按**Copy invitation link**并移交链接。该链接只在此时显示；它只能使用一次，并在 24 小时后过期。
5. 如果链接丢失或已过期，请按**Create a new invitation link**；之前的链接将停止生效。要撤回邀请，请按**Revoke invitation**。
6. 被邀请的人打开链接、登录、检查邀请授予的内容，然后按**Accept invitation**。重新登录后，他们将使用您设置的授权进行工作；此时该成员显示为**有效**和**Invitation accepted**。
7. 要更改现有成员的授权，请按**Edit grant**，然后按**Save grant**。每次保存都会创建一个新的授权修订版本；较早的修订版本保留在**Grant history**中。
8. 对于临时移交，请使用**Delegate from this member**，并填写受托人、**生效起始**、**有效期至**、**理由**和**Delegated permissions**。
9. 要停止访问，请使用**Lifecycle**中的**暂停**；**恢复**会重新开放访问。**Revoke membership**是最终操作。

## 状态含义
- **Invited：**成员资格在等待被邀请的人。它不授予任何权限，也不在任何地方（包括任何其他组织）预留该账户。
- **邀请待处理 / 邀请已过期 / 邀请已替换 / 邀请已撤销 / Invitation accepted：**最新邀请链接的状态。已过期、已替换或已撤销的链接永远不能被接受。
- **有效 / 已暂停 / 已撤销：**成员资格的生命周期。已暂停或已撤销成员的下一次请求会被拒绝。
- **授权来源 — 在此管理：**该授权是在本页上授予的，可以在此更改。
- **授权来源 — 运营方配置：**该授权来自服务器配置（bootstrap/break-glass），不能在此编辑。
- **授权来源 — 无授权：**存在记录，但不授予任何权限。
- **您未持有 / 您未持有此角色包的所有权限：**您不能授予此权限或角色包，因为您本人未持有。
- **Saved. The change takes effect on the member's next request.**被邀请成员的访问从接受邀请后的下一次登录开始。

## 不能做的事 / 注意
- 您不能授予您本人未持有的权限、船舶或租户范围访问权限。
- 您不能更改自己的成员资格；最后一位有效的管理员不能被移除。
- 一个账户只能在一个组织中持有已接受的成员资格。邀请绝不会转移已属于其他组织的账户；此时被邀请的人只会看到邀请无法被接受。
- 请像对待钥匙一样对待邀请链接：除非您输入了预期的 subject，否则任何持有该链接并登录的人都可以接受邀请。不要将其发布在共享渠道中。始终传递完整的链接：**#** 之后的秘密部分只由浏览器读取，绝不会到达服务器或其日志。
- 决定、核验和批准权限绝不会包含在角色包中。只有持有这些权限的管理员才能逐一授予它们。受任命限制的操作（例如拖轮或开航决定）还需要运营方任命。授予角色包并不会任命任何人为船长或核验人。
- 您不能批准您本人作为来源方或受托人的委托。委托绝不会超出来源方当前的权限，也绝不会是租户范围的。
- POSEIDON 不保存任何密码，只保留邀请链接的指纹，并且绝不会在列表中回显 IdP subject。

## 出现问题时
- **This identity is configured by the operator, already a member here or already invited here.**请改为打开现有成员，或先撤销旧的邀请。
- **被邀请的人看到“此邀请无法被接受”：**链接已过期、已被使用、已被替换或已被撤销，属于另一个账户，或其账户已属于某个组织。检查**Invitation**状态，必要时按**Create a new invitation link**。
- **链接未被复制：**选择链接字段并手动复制。
- **Exceeds your own authority：**选择范围更窄的角色包或范围，或请持有该权限的管理员处理。
- **记录在此期间已更改：**按**Reload current state**并重新进行更改。
- **The outcome is unknown. Retry with the same request or reload.**您可以安全地重新发送同一命令。
- **Not the trusted identity provider：**检查签发方。如果账户来自另一个 IdP，请联系系统管理员（13.03 §10）。
