## 本页用途
执行控制台以时间线的形式记录已提交拖轮任务的**实际执行**：开始、观测、**暂停 / 恢复 / 中止 / 完成**操作以及之后的核验。它回答的问题是：“作业何时开始？拖缆何时连接和释放？记录了哪些观测？作业处于什么状态？记录是否已核验？”开始和状态转换是执行拖轮上的拖轮船长或船长的人工记录；控制台绝不签发 GO。

## 谁使用本页
- **拖轮船长 / 船长：**开始作业，并记录开始/暂停/恢复/中止/完成时间线及其证据（13.03 §3）。
- **核验人（具有执行核验权限的人员）：**核验已完成或已中止的记录，或驳回其核验（13.03 §1）。
- **拖轮作业协调员 / 岸基运营：**跟踪已完成任务的证据完整性和历史；他们不能开始或中止作业（13.03 §7）。

## 开始之前
- 从**拖轮作业**打开拖轮，并从**选择已提交的拖轮任务**中选择任务。
- 要开始作业，以下各项都必须为当前有效：拖轮的有效指派、已批准的**拖带计划**（拖轮必须在计划中）、已发布且已由每位参与者确认的**拖带风险与简报**，以及**作业就绪关口**上与当前评估绑定的**GO**记录。
- 开始和状态转换需要服务器中已记录的该拖轮**任命**（拖轮船长或船长）。

## 操作步骤
1. 在**开始条件**部分，阅读每艘拖轮的**就绪决定**和**阻碍项**。
2. 如果没有阻碍项，请以船上被任命人员的身份阅读确认文本，选择您的**任命**，可选择输入**开始位置**，然后按**开始作业**。
3. 执行开启后，跟踪**状态**、**核验**以及台账字段（拖缆已连接/已释放、观测到的最大拖力、通信、绞车、应急释放试验、有效分钟数）。
4. 在**记录观测**中，选择观测类型（例如拖缆已连接、拖力、通信检查、天气、绞车状态、应急释放试验、位置、证据、备注），输入数值并按**记录观测**。
5. 在**拖轮船长操作**中，选择**操作**（暂停、恢复、中止、完成），并输入您的**任命**和**理由**。中止和完成需要至少 20 个字符的理由，并会打开**结束位置**字段；没有结束位置时不接受完成。
6. 如果列出了**完成阻碍项**，请将其清除；例如，如果拖缆仍处于连接状态，请先记录其释放。
7. 作为核验人，写下理由并按**核验记录**或**驳回核验**。
8. 在**时间线**中按顺序查看每个事件。

## 状态含义
- **进行中 / 已暂停 / 已完成 / 已中止：**作业状态。已完成并不表示记录已核验。
- **待处理 / 已核验 / 已驳回：**核验状态。已完成 ≠ 已核验；核验是另一人的记录。
- **良好 / 丢失 / 通过 / 未通过 / 有条件 / 未知：**通信、绞车和应急释放观测的结果。未知表示没有记录任何内容；它绝不能代替“良好”或“通过”。
- **安全事件 — 未知：**此控制台不统计安全事件；不会得出“没有事件”的结论。
- **GO（人工记录） / NO GO（人工记录）：**拖轮船长或船长在就绪关口上记录的决定。

## 不能做的事 / 注意
- 岸基用户、AI 和系统身份不能开始或中止作业。岸基指派绝不能推翻拖轮船长在船上的安全决定（13.03 §7）。
- 只有被任命的拖轮船长或船长才能暂停、恢复、中止或完成作业。作业进行期间始终可以中止。
- 开始或结束作业的人不能核验同一记录；核验在作业结束后进行。
- 台账只能追加；已记录的事件绝不会被删除或更改。
- 离线时不会发送任何命令。观测可以在**拖轮离线作业**中排队；开始、状态转换和核验仍需在线进行。

## 出现问题时
- **出现“服务器列出了缺失或阻碍的条目。”消息：**清除**阻碍项**或**完成阻碍项**中的代码（例如计划未批准、简报确认待处理、GO 记录缺失或不是当前有效的）。
- **出现“记录已更改或命令冲突。”消息：**使用**重新加载最新版本**审核该记录。
- **出现“结果未知。”消息：****重试**会再次发送完全相同的命令。
- **未获授权：**检查您的角色、拖轮和任命上下文；必要时联系您的租户管理员（13.03 §10）。
