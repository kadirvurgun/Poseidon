## 本頁用途
風險範本庫按修訂版本管理整個租戶使用的風險評估範本（作業類型、危害、預設控制措施、必要屏障、SMS 和要求來源）以及風險方法（矩陣）。它回答的問題是：「哪個已發布的範本適用於此作業類型？哪個修訂版本正在生效？」本頁**僅為開發目標**：此處的發布是已記錄的 HSEQ 人工紀錄，不是許可、專家風險接受或 HSE 關卡放行（13.03 §4）。

## 誰使用本頁
- **DPA / HSEQ：**作為風險治理的一部分，準備、審核並發布範本修訂版本、屏障和風險矩陣（13.03 §4）。
- **船長、拖船船長和船員：**閱讀已發布的範本，並為某個範本傳送**船員建議**。

## 開始之前
- 讀取需要範本讀取權限。撰寫和發布範本需要租戶範圍以及範本寫入或發布權限。傳送建議只需要範本建議權限。
- 建立和發布風險方法是另外的權限，並且需要租戶範圍。
- 風險指令需要目前的線上連線；離線時不會排入佇列或核准任何內容。

## 操作步驟
1. 在清單中查看範本。每一列顯示狀態、**目前**修訂版本和**建議**數量。開啟一個範本。
2. 對於新範本，按**新增範本**。填寫**範本代碼**、**標題**、**作業類型**、**船舶／拖船範圍**、**核准負責人**、**變更原因**、**必要屏障**、**SMS / 要求來源**和**危害**，然後按**儲存草稿**。
3. 在草稿修訂版本上按**提交審核**。缺漏的項目會作為阻礙項目列出。
4. 發布人輸入**生效日期**和至少 10 個字元的**理由**，然後按**發布（HSEQ 人工紀錄）**或**退回**。
5. 要變更已發布的範本，請寫下理由並按**開始新修訂**；較早的修訂版本不會改變。
6. 船員在**送出建議**中寫下建議並送出。獲授權人員使用**接受**或**拒絕**並附理由進行審核。
7. 在**風險方法（矩陣）**中，使用**新增方法**輸入**方法代碼**、**可能性代碼**、**嚴重性代碼**和**矩陣儲存格**；由另一人使用**發布方法**發布。

## 狀態含義
- **草稿 / 審核中 / 已退回 / 已發布 / 已取代：**範本修訂版本的生命週期。
- **目前 / 已排程 / 未生效：**生效檢視。生效日期已到的最新已發布修訂版本為**目前**；生效日期在未來的為**已排程**。未來的修訂版本絕不會提前取代較早的修訂版本。
- **未知：**該欄位未填寫；空值絕不會用預設值填充。
- **無已發布的風險方法：評級保持未評估。**系統不提供任何預設矩陣或門檻。

## 不能做的事 / 注意
- 修訂版本的撰寫人或提交人不能發布同一修訂版本；發布是另外的人工紀錄（職責分離）。
- 發布不是許可、專家風險接受或已核准的正式目錄。
- 範本只能以**副本**形式套用於風險評估；它不攜帶任何評級、簽名、參與者確認、核准或確認收悉。範本變更時，現有評估不會自行改變。
- 已發布的修訂版本絕不會被編輯；要變更它，請開始新的修訂。

## 發生問題時
- **在完成所列項目之前被封鎖。**完成阻礙項目後重新提交。
- **此紀錄已在別處被變更。**按**重新載入**查看目前修訂版本。
- **您無權執行此操作（職責分離或範圍）。**發布必須由未撰寫該修訂版本的另一位獲授權人員完成；如果缺少權限，請聯絡租戶管理員（13.03 §10）。
- **此操作已不適用於目前狀態。請重新載入。**修訂版本的狀態已經改變。
