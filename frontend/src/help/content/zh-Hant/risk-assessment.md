## 本頁用途
風險評估頁面記錄船舶上某項工作或作業的危害、潛在後果、控制措施、初始風險和殘餘風險以及停止作業條件。它回答的問題是：「這項工作的危害和控制措施是否已被考慮、審核並由參與人員確認？」本頁**僅為開發目標**：此處的核准是已記錄的人工審核，不是許可、專家風險接受或 HSE 關卡放行（13.03 §2, §4）。

## 誰使用本頁
- **船長和拖船船長：**為船舶或拖船上的工作安排編製評估，並作出停止作業的決定。決定權始終屬於他們（13.03 §2, §3）。
- **DPA / HSEQ：**監督風險治理並記錄審核決定（13.03 §4）。
- **Crew / OOW / 輪機員：**作為參與人員，為自己確認或對已核准的評估提出異議（13.03 §6）。

## 開始之前
- 選擇船舶以開啟其風險評估。讀取需要風險讀取權限；撰寫草稿需要風險寫入權限以及該船舶的編輯範圍。審核決定需要風險核准權限；確認需要風險確認權限。
- 評級需要租戶中有已發布的風險方法（矩陣）。沒有時，評級保持**未評估**。由租戶 HSEQ 負責人設定矩陣，並由另一人發布（風險範本庫頁面）。
- 風險指令需要目前的線上連線；離線時不會排入佇列或核准任何內容。

## 操作步驟
1. 選擇船舶並從清單中開啟一項評估，或按**新增評估**。
2. 輸入**評估編號**。可選擇輸入**作業類型**，並使用**從已發布範本開始（僅副本）**選擇相符的範本；範本只會被複製到新草稿中。
3. 填寫**標題**、**作業／工作背景**、**作業類型**、**工作範圍**和**風險方法**。對於**需要停止作業**，選擇**是**、**否**或**未知**，必要時寫下停止作業條件。
4. 使用**新增危害**為每項危害輸入**作業步驟**、潛在後果、**初始風險**和**殘餘風險**（可能性、嚴重性、理由）。使用**新增控制措施**新增**控制措施**、**控制措施負責人**和屏障參照。
5. 在**參與人員**中，每行寫一個操作者 ID 和角色。必要時使用**新增關聯**連結相關紀錄。
6. 按**儲存草稿**，然後按**提交審核**。**封鎖項目**列出缺少的內容。
7. 審核人寫下至少 10 個字元的**理由**，然後按**核准（人工審查紀錄）**或**退回**。
8. 核准後，每位參與者為自己按**確認**，或附理由按**提出異議**。如需變更，請使用**修訂（開啟新草稿）**。

## 狀態含義
- **草稿 / 審核中 / 已退回 / 已核准（人工紀錄）：**評估的生命週期。已核准是人工審核紀錄，不是許可。
- **未評估 / 方法未設定：**沒有評級。系統不使用任何預設矩陣、乘法或低/中/高門檻。
- **需要停止作業 — 未知：**尚未作出決定；它絕不會被理解為「否」。
- **核准前不適用確認 / 確認待處理 / 所有參與者已確認 / 有異議 – 未解決：**參與者確認狀態。異議絕不會因他人的確認而被關閉。
- **固定後已變更 / 不可用：**連結的紀錄在固定的修訂版本之後發生了變更，或已無法讀取；請重新審核。

## 不能做的事 / 注意
- 審核週期的撰寫人或提交人不能核准同一項評估（職責分離）。
- 每個人只能為自己確認，且只能確認確切的已核准修訂版本。
- 此處的核准不是許可、專家風險接受或 HSE 關卡。開始或停止作業的決定始終由船長或拖船船長作出。
- 從範本開始的草稿不攜帶任何評級、簽名、參與者確認或核准。
- 離線時，評估不能提交、核准或確認。

## 發生問題時
- **在完成所列項目之前被封鎖。**完成封鎖項目後重新提交。
- **此紀錄已在別處被變更。**按**重新載入**查看目前修訂版本，然後重複該操作。
- **您無權執行此操作（職責分離或範圍）。**請另一位獲授權人員進行審核，或檢查您的角色和船舶情境；必要時聯絡租戶管理員（13.03 §10）。
- **以您目前的存取權限無法使用風險工作區。**檢查您的權限。
- 如果評級看起來出乎意料，請檢查風險方法及其修訂版本；詢問控制負責人或 HSEQ 負責人（13.03 §10）。
