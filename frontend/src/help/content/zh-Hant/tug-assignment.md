## 本頁用途
本頁顯示已提交拖船任務的**拖船指派提議**及其與其他任務的**衝突**。它回答的問題是：「為這個任務提議了哪艘拖船？擔任什麼角色、在哪個時間窗口？它是否與其他工作衝突？拖船船長是否已接受該提議？」岸上提議，拖船船長確認；本頁不作出派遣或放行決定。頂部的提示也這樣說明：「系統絕不簽發 GO。」

## 誰使用本頁
- **拖船作業協調員 / 岸上營運：**在任務看板上審核衝突和就緒情況後提出指派提議（13.03 §7）。
- **拖船船長：**在情境中確認針對本拖船的提議，並接受或拒絕（13.03 §3）。

## 開始之前
- 從**拖船作業**開啟拖船；如果未選擇拖船，本頁會引導您前往該處。
- 提議需要拖船寫入和計畫寫入權限；任務必須處於**已提交**狀態。
- 回應需要伺服器中已記錄的該拖船**任命**（拖船船長或船長）。提出提議的人不能回應該提議。

## 操作步驟
1. 從**選擇已提交的拖船任務**中開啟任務編號。任務詳細資訊中的**指派與就緒**連結也會開啟本頁。
2. 對於現有提議，閱讀**狀態**、**拖輪船長確認**、**角色**、**計畫開始**和**計畫結束**。
3. 在**衝突**中，查看與其他任務的時間和資源衝突、其結果標記和原因代碼。
4. 對於新提議，在**提議指派**表單中選擇**拖船**、**計畫開始**、**計畫結束**和**角色**（主拖、協助、護航），然後按**提議指派**。
5. 作為拖船船長，選擇您的**任命**，必要時新增**理由**，然後按**接受**或**拒絕**。拒絕時必須填寫理由。
6. 要撤銷提議，請輸入理由並按**撤回提議**。
7. 使用每個提議下的**作業就緒關卡**和**船員與拖帶能力**連結進入就緒畫面。

## 狀態含義
- **已提議 / 已撤回：**提議的生命週期。已提議並不表示拖船已被派遣。
- **待處理 / 已接受 / 已拒絕：**拖船船長對提議的回應。已接受確認的是提議範圍；它不是 GO 決定。
- **通過 / 未通過 / 未知：**衝突檢查的結果。未知表示沒有足夠的來源資料進行檢查；它絕不表示「沒有衝突」。
- **未發現衝突；輸入可能仍不完整。：**未發現衝突，但這不是完整的資格結果。
- **此提議後請求已變更；需要新的提議。：**任務請求在提議所依據的修訂版本之後發生了變更。

## 不能做的事 / 注意
- 岸上指派提議絕不能推翻拖船船長在船上的安全決定（13.03 §3, §7）。
- 提議人不能接受自己的提議；回應只屬於被任命到該拖船的人員。
- 不能為草稿或已取消的任務提出提議。
- 離線時指令被停用。

## 發生問題時
- **出現「結果不確定」訊息：****重試**會傳送同一指令；不要建立新的提議。
- **出現「紀錄已變更」訊息：**使用**重新載入**審核目前紀錄，然後再次操作。
- **「您無權執行此操作。」 / 「您無權存取此紀錄。」：**檢查您的角色、拖船和任命情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **非預期的衝突：**記下原因代碼，並與另一任務的負責人一起審核。
