## 本頁用途
就緒關卡根據來源檢查對拖船指派的作業就緒情況進行評估，**僅作為建議**，並允許被任命的拖船船長或船長記錄附理由的**GO/NO-GO 決定**。它回答的問題是：「船員、設備、PMS、證書、通訊、天氣、繫柱拉力餘量、指派和簡報檢查的結論是什麼？存在哪些阻礙項目？」評估不是決定：「系統絕不簽發 GO；只有被任命的船長或拖船船長才能附理由記錄 GO/NO-GO 決定。」

## 誰使用本頁
- **拖船船長 / 船長：**審核評估和阻礙項目，並記錄 GO 或 NO-GO 決定（13.03 §3）。
- **拖船作業協調員 / 岸上營運：**追蹤就緒情況和阻礙項目；他們不作決定（13.03 §7）。

## 開始之前
- 從指派開啟本頁：在**指派與衝突**中，使用某個提議下的**作業就緒關卡**連結。未選擇指派時，本頁顯示「請從任務的指派清單中選擇一個指派。」
- 記錄決定需要拖船寫入權限以及伺服器中已記錄的該拖船**任命**（拖船船長或船長），並且指派必須仍處於已提議狀態。
- 沒有簡報就沒有 READY：**拖帶風險與簡報**必須已發布，並已由每位參與者確認（13.03 §3）。

## 操作步驟
1. 閱讀**評估**列上的狀態標記。旁邊的附註說明「僅為建議，不是 GO 決定。」
2. 檢查**所需繫柱拉力 (t)**、**已驗證可用繫柱拉力 (t)**和**繫柱拉力餘量 (t)**。缺漏的值顯示為「未知」。
3. 審核**關鍵阻斷項**、**審查原因**和**條件**下的代碼。
4. 在類別表中，查看每個類別（船員、拖帶能力、設備、拖帶設備、PMS 與缺陷、證書、通訊、天氣、繫柱拉力餘量、指派、拖帶風險與簡報）的結果。如需詳細資訊，請閱讀**來源檢查**表中的原因代碼。
5. 如果您擁有決定權，請在**記錄船長決定**表單中選擇**NO-GO**或**GO**，輸入您的**任命**和**理由**，然後按**記錄**。
6. 在**船長決定**清單中查看已記錄的決定。

## 狀態含義
- **就緒（READY）：**所有來源檢查均通過（沒有阻礙項目、未知項目或條件）。這是資訊，不是決定；GO 決定仍由拖船船長或船長記錄。
- **有條件（CONDITIONAL）：**「條件」中的條件適用。GO 被停用，頁面會說明：「此評估為 CONDITIONAL。GO 需要 READY 評估：沒有任何來源規定哪些條件可以允許 GO，因此伺服器會拒絕。請解決這些條件並重新評估，或記錄 NO-GO。」
- **未就緒（NOT_READY）：**至少存在一個關鍵阻礙項目。
- **需要審查（REVIEW_REQUIRED）：**部分來源未知或等待審核。未知的檢查絕不會被計為「就緒」。
- **通過 / 未通過 / 未知：**單個類別或檢查的結果。
- **GO / NO-GO：**由拖船船長或船長記錄的人工決定和理由。

## 不能做的事 / 注意
- GO 只能針對 READY 評估記錄；對於 CONDITIONAL、NOT_READY 或 REVIEW_REQUIRED，伺服器會拒絕 GO。本頁只在 READY 評估上啟用 GO；否則會顯示「GO 只能針對 READY 評估記錄。」NO-GO 始終可以附理由記錄。
- 當風險與簡報不完整或缺少參與者確認時，不存在 READY；此時 GO 選項被停用（13.03 §3）。
- 岸上使用者的指派提議絕不能推翻拖船船長在船上的安全決定（13.03 §7）。
- 如果評估在您作出決定之前發生變化，該決定會被拒絕；請重新審核目前評估。
- 離線時指令被停用。

## 發生問題時
- **出現「評估已變更」訊息：**使用**重新載入**，審核目前評估後重新決定。
- **出現「結果不確定」訊息：****重試**會傳送同一指令。
- **非預期的就緒結果：**開啟類別表和來源檢查原因；與控制負責人或領域專家一起審核（13.03 §10）。
- **未獲授權：**檢查您的角色、拖船和任命情境；必要時聯絡您的租戶管理員（13.03 §10）。
