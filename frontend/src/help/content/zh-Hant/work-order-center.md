## 本頁用途
工單中心保存所選船舶的**工單草稿及聲明的執行記錄**。它回答的問題是：「這艘船上有哪些工單？哪些已發布、已執行、已提交證據並已由人查證？」每個已儲存的修訂版本都保留在不可變更歷史中。查證和關閉不是恢復使用、許可或風險核准。

## 誰使用本頁
- **輪機長 / 技術主管：**開立、發布、查證和關閉計畫內和計畫外工單（13.03 §5）。
- **輪機員 / 船員：**開始已分派的工作，並記錄和提交讀數、備件、照片和文件證據（13.03 §6）。

## 開始之前
- 讀取需要 `workorder.read`、`equipment.read` 和 `maintenance.read`。草稿需要 `workorder.write`，發布需要 `workorder.release`，執行需要 `workorder.execute`，查證需要 `workorder.verify`，關閉需要 `workorder.close`。
- 發布、查證和關閉需要已登入的人工使用者。
- 從**選擇船舶或拖船**中選擇正確的船舶。

## 操作步驟
1. 選擇船舶。在**已記錄工單**中，使用**搜尋傳回的工單編號**篩選本頁，並開啟一筆紀錄。
2. 對於新工作，按**新增工單草稿**，填寫欄位並按**儲存未經評估的草稿**。不完整的草稿可以儲存。
3. 在**執行與證據**中，如果您有發布權限，請在**必要證據政策**下選擇**宣告必要證據**，勾選證據類型並按**發布工單**。如果您未宣告就發布，查證會一直被阻止，直到發布人使用**變更必要證據** → **儲存必要證據**。
4. 執行人按**開始工作**，填寫**讀數**、**已消耗備件**、**照片和文件證據**、**已完成工作**和**發現事項**，按**儲存證據**，然後按**提交證據**。
5. 由未執行該工作的獲授權查證人審核證據。他們按**記錄驗證**，或選擇**退回原因**並按**退回執行人**。
6. 對於已查證的工單，由獲授權人員按**記錄關閉**。
7. 在**不可變更工單歷史**中查看較早的修訂版本。如果需要停工紀錄，請使用**開啟連結停機草稿**。

## 狀態含義
- **未發布執行。 / 已發布 / 進行中：**工作尚未發布、已發布或正在執行。
- **證據已提交：**執行人聲明了工作和證據。這並不表示已查證。
- **已驗證（人工記錄）：**由未執行該工作的獲授權查證人記錄。**已關閉（人工記錄）**是另外的步驟。
- **缺少必要證據 / 已提供，待人工查證 / 已由人查證：**必要證據關卡的狀態。
- **需要審查：政策未設定：**未宣告必要證據。未設定絕不表示沒有任何要求；查證保持被阻止。
- **已被驗證人退回：**工作已退回給執行人，並顯示原因。

## 不能做的事 / 注意
- 如果工作是您執行的，您不能查證或關閉它。頁面會顯示「您執行了此工作，因此不能查證或關閉它。」
- 證據已提交、已查證和已關閉是彼此獨立的人工紀錄。本頁絕不會宣告設備可以恢復使用。
- 「已儲存的工單來源」摘要描述已儲存的草稿欄位，並說明：「發布、證據記錄、獨立查證和關閉在執行面板中記錄。提交的證據只能透過獨立的人工查證被接受，絕不能由完成工作的人接受；沒有另外的證據接受步驟，查證也不是恢復使用的決定。」這些操作在**執行與證據**中進行。
- 讀數按聲明保存；不進行單位換算，也不套用門檻。
- 離線證據佇列只有在存在已核准的離線政策且工作正在進行時才能使用。衝突絕不會被自動合併；請使用**開啟衝突中心**，由人作出決定。

## 發生問題時
- **紀錄已變更，或此操作在目前狀態下不被允許：**使用**重新載入**讀取目前紀錄後再試一次。
- **結果未知：****重試同一命令**會傳送同一指令；它不會建立新紀錄。
- **缺少權限或人工權限：**檢查您的角色和船舶情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **必要證據關卡拒絕了此操作：**補全缺漏的證據類型。如果紀錄無法查證，請與查證人一起檢查證據及其出處（13.03 §10）。
