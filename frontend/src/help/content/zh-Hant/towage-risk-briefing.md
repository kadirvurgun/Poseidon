## 本頁用途
本頁為已提交的拖船任務準備並發布**拖帶風險與簡報紀錄**，並收集參與人員的**確認紀錄**。它回答的問題是：「簡報中介紹了哪些條件、危害、預防性和減緩性屏障、停止作業權限和緊急安排？連結風險評估的狀態如何？每位參與者是否都已確認所發布的修訂版？」發布簡報是被任命的船長或拖船船長的人工紀錄；它不是 GO 決定，也不是許可。簡報不完整會阻擋 READY。

## 誰使用本頁
- **拖船船長 / 船長：**準備並發布簡報，並確保在風險和簡報完成之前不作出 READY 決定（13.03 §3）。
- **船員和其他參與人員（引水人、駕駛員、甲板船員、輪機員）：**在正確的角色情境中確認或對已發布的簡報提出異議（13.03 §6）。
- **拖船作業協調員：**追蹤簡報和確認狀態（13.03 §7）。

## 開始之前
- 從**拖船作業**開啟拖船，並從**選擇已提交的拖船任務**中選擇任務。
- 該任務的**拖帶計畫**必須已核准，且連結的風險評估必須已核准；否則無法發布簡報。
- 發布需要伺服器中已記錄的協調拖船的**任命**（拖船船長或船長）。發布還需要風險評估讀取權限以及對協調拖船的拖船寫入權限。只有參與人員清單中的人員才能進行確認。

## 操作步驟
1. 在頂部一列閱讀**狀態**、**修訂版**、**確認收悉**、**風險狀態**和**計畫狀態**。
2. 在**就緒輸入（簡報不完整將阻擋 READY）**中，查看傳送到就緒關卡的結果和原因代碼。
3. 填寫**簡報中確認的條件**（天氣、水流、能見度）、**危害**、**預防性屏障**、**減緩性屏障**、**停止作業權限**和**緊急安排**。
4. 輸入**關聯風險評估 ID**；在**參與人員**中，使用**新增**輸入每位參與者的**人員 ID**和**角色**。
5. 使用**建立草稿**或**儲存草稿**儲存；當**提交前缺漏項目**為空時，選擇**任命**並按**發布簡報**。
6. 作為參與者，閱讀已發布的修訂版並按**確認**。如果您不同意，請寫下至少 10 個字元的**理由**並按**提出異議**。
7. 如果簡報必須變更，請寫下理由並使用**修改**。**確認紀錄**和**修訂紀錄**清單顯示歷史。

## 狀態含義
- **草稿 / 已發布：**簡報狀態。已發布表示可以開始確認；它本身不是就緒結果。
- **未發布 / 待處理 / 已完成 / 有異議：**參與者確認狀態。只有當每位參與者都已確認所發布的修訂版時，才會變為**已完成**。
- **已核准並已確認 / 關注 / 受阻 / 需要審查：**連結風險評估的狀態。
- **通過 / 未通過 / 未知：**傳送到就緒關卡的檢查結果。缺漏或未發布的簡報以及待處理的確認都是會阻擋 READY 的**未通過**。

## 不能做的事 / 注意
- 在風險和簡報完成且參與者確認已記錄之前，不會作出 READY 決定（13.03 §3）。
- 提出異議會使確認狀態變為**有異議**，並向就緒關卡傳送「未通過」，因此 READY 和 GO 都會被阻擋。理由顯示在**確認紀錄**中。同一修訂版的確認不能變更；要消除異議，需要修改簡報（新修訂版）、重新發布，並由每位參與者重新確認。
- 如果計畫或風險評估在簡報之後發生變更，必須重新審核簡報；較早的確認不計入新的修訂版。
- 任何人都不能代替他人確認；每位參與者記錄自己的確認（13.03 §6）。
- 離線時本頁不會傳送任何指令。確認可以在**拖船離線作業**中排入佇列。

## 發生問題時
- **出現「缺少必要區段。」訊息：**補全缺漏的代碼；檢查計畫和風險評估是否已核准。
- **出現「紀錄已變更」訊息：**使用**重新載入**審核目前簡報。
- **出現「結果未知」訊息：****重試**會再次傳送同一請求。
- **未獲授權：**檢查您的角色、拖船和任命情境；必要時聯絡您的租戶管理員（13.03 §10）。
