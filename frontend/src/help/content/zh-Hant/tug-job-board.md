## 本頁用途
任務看板列出所選拖船情境中用於計畫的**拖船任務請求草稿**。它回答的問題是：「有哪些請求？它們請求的時間範圍是什麼？需要多少艘拖船和多大的繫柱拖力（BP）？計畫還缺少什麼？」看板只顯示草稿聲明；它不是作業指派、資格、許可或安全核准。

## 誰使用本頁
- **拖船作業協調員 / 岸上營運：**查看請求，追蹤衝突和就緒資訊，並準備指派提議（13.03 §7）。
- **拖船船長：**提前查看本拖船即將進行的工作（13.03 §3）。

## 開始之前
- 在頂部情境列中選擇**正確的公司和拖船**。看板只顯示此情境中的請求。
- 您需要讀取權限才能查看看板。建立請求需要寫入權限；沒有該權限時不會顯示「新增請求」按鈕。

## 操作步驟
1. 在頂部摘要中，查看本頁上的請求數量、有已記錄阻礙項目的任務、等待就緒審核的任務以及就緒情況未知的任務。**計數僅涵蓋此頁。**
2. 必要時，在**搜尋請求**中輸入任務編號或受助船舶名稱，選擇**優先級**、**狀態**和**時間範圍**篩選條件，然後按**套用篩選**。
3. 在每一列中，閱讀請求的時間範圍（UTC）、指派草稿、所需拖船數量、所需 BP 與計畫能力的對比、就緒情況和作業衝突。
4. 開啟某一列的**原因 / 下一步操作**，查看已指派的拖船參照、比較範圍和已記錄的理由。
5. 使用**開啟任務**進入請求的詳細資訊。
6. 對於新請求，按**新增請求**開啟**任務受理**（需要寫入權限）。
7. 使用**重新整理看板**重新讀取資料，使用**上一頁** / **下一頁**查看其他頁面。

## 狀態含義
- **草稿 / 已提交 / 已取消：**請求的生命週期狀態。提交是將請求記錄用於計畫；它不是核准、指派或就緒決定。
- **受阻：**請求有已記錄的阻礙項目。原因見「原因 / 下一步操作」。
- **需要審查：**就緒資訊在等待獲授權人員審核。
- **未知：**沒有足夠的來源資料來判斷就緒或衝突。未知不等於「就緒」或「沒有衝突」，看板也不會據此得出任何就緒結論。
- **需要獲授權的人工審核 / 需要邊界銜接審核：**兩個請求可能在時間上重疊或首尾相接。由人作出決定。
- **檔案 BP（未經查證）：**顯示的繫柱拖力是聲明值，不是測量值或已查證的值。

## 不能做的事 / 注意
- 看板絕不會宣告某個請求「就緒」或「安全」。岸上指派提議不會取消拖船船長在船上的安全權限（13.03 §7）。
- 已提交或已取消請求的欄位不能在看板上變更；已取消的請求不能重新啟動，請改為新增一個請求。
- 時間範圍篩選使用伺服器時間。沒有開始時間的請求以「未知」保留在清單中。
- 離線時顯示的資料可能是舊的，且無法重新整理看板。

## 發生問題時
- **目前看板不可用：**檢查您的網路連線並使用「重新整理看板」。
- **沒有請求草稿：**如果您套用了篩選條件，請嘗試其他搜尋或優先級；新請求會出現在此情境中。
- **無法存取：**檢查您的角色和拖船情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **非預期的阻礙項目或審核：**開啟「原因 / 下一步操作」，並與請求負責人一起審核已記錄的理由。
