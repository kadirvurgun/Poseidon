## 本頁用途
「使用者與權限」頁面管理您的工作區中的**成員資格**。它回答的問題是：「這個人可以看到什麼、做什麼，以及在哪些船舶上？」帳戶本身（使用者名稱、密碼、MFA）存在於中央身分提供者（IdP）中，而不在 POSEIDON 中。本頁將該帳戶**邀請**為成員，並授予角色包、權限和船舶範圍（13.03 §9）。新成員是被邀請的：在本人登入並接受邀請之前，邀請不授予任何權限。

## 誰使用本頁
- **租戶管理員：**依最小權限原則分配使用者、角色、船舶和物件範圍，邀請新成員，並管理委派和暫停（13.03 §9）。
- 其他具有成員資格讀取權限的使用者可以檢視清單，但不能變更。
- **被邀請的人**只開啟邀請連結；他們絕不會看到本頁。

## 開始之前
- 檢視需要成員資格讀取權限；變更需要成員資格管理權限以及租戶範圍的管理權限。只有讀取權限時，您會看到「您可以檢視但不能變更成員資格。」
- 此人需要在身分提供者中有一個帳戶。**Expected IdP subject (optional)**會將邀請限制為該帳戶；沒有填寫時，任何使用該連結登入的人都可以接受邀請。
- 請規劃一個可信的管道來移交邀請連結（例如貴組織自己的訊息系統）。POSEIDON 不傳送電子郵件。
- 您只能授予自己擁有的權限。您自己的成員資格由另一位管理員編輯。
- 成員資格管理需要即時的伺服器連線；離線時不能進行任何變更。

## 操作步驟
1. 在**Members**清單中查看成員。按**狀態**（例如**Invited**）和**Role bundle**篩選，然後按**Apply**。要搜尋，請輸入成員資格或帳戶 ID 前綴或確切的 IdP subject，然後按**搜尋**。
2. 使用**開啟**開啟一個成員。審核**Effective permissions**、**船舶範圍**、**Invitation**、**Grant history**和**Delegations**。
3. 要邀請成員，請按**Add member**。檢查**IdP issuer**，可選擇輸入**Expected IdP subject (optional)**，選擇至少一個**Role bundle**，必要時新增**Individual permissions**，並設定範圍（租戶範圍或至少一艘船舶）。然後按**Create membership**。
4. 該成員以**Invited**狀態開啟，並顯示**Invitation link**。按**Copy invitation link**並移交連結。該連結只在此時顯示；它只能使用一次，並在 24 小時後過期。
5. 如果連結遺失或已過期，請按**Create a new invitation link**；之前的連結將停止生效。要撤回邀請，請按**Revoke invitation**。
6. 被邀請的人開啟連結、登入、檢查邀請授予的內容，然後按**Accept invitation**。重新登入後，他們將使用您設定的授權進行工作；此時該成員顯示為**有效**和**Invitation accepted**。
7. 要變更現有成員的授權，請按**Edit grant**，然後按**Save grant**。每次儲存都會建立一個新的授權修訂版本；較早的修訂版本保留在**Grant history**中。
8. 對於臨時移交，請使用**Delegate from this member**，並填寫受託人、**生效起始**、**有效期至**、**理由**和**Delegated permissions**。
9. 要停止存取，請使用**Lifecycle**中的**暫停**；**恢復**會重新開放存取。**Revoke membership**是最終操作。

## 狀態含義
- **Invited：**成員資格在等待被邀請的人。它不授予任何權限，也不在任何地方（包括任何其他組織）保留該帳戶。
- **邀請待處理 / 邀請已過期 / 邀請已取代 / 邀請已撤銷 / Invitation accepted：**最新邀請連結的狀態。已過期、已取代或已撤銷的連結永遠不能被接受。
- **有效 / 已暫停 / 已撤銷：**成員資格的生命週期。已暫停或已撤銷成員的下一次請求會被拒絕。
- **授權來源 — 在此管理：**該授權是在本頁上授予的，可以在此變更。
- **授權來源 — 營運方設定：**該授權來自伺服器設定（bootstrap/break-glass），不能在此編輯。
- **授權來源 — 無授權：**存在紀錄，但不授予任何權限。
- **您未持有 / 您未持有此角色包的所有權限：**您不能授予此權限或角色包，因為您本人未持有。
- **Saved. The change takes effect on the member's next request.**被邀請成員的存取從接受邀請後的下一次登入開始。

## 不能做的事 / 注意
- 您不能授予您本人未持有的權限、船舶或租戶範圍存取權限。
- 您不能變更自己的成員資格；最後一位有效的管理員不能被移除。
- 一個帳戶只能在一個組織中持有已接受的成員資格。邀請絕不會轉移已屬於其他組織的帳戶；此時被邀請的人只會看到邀請無法被接受。
- 請像對待鑰匙一樣對待邀請連結：除非您輸入了預期的 subject，否則任何持有該連結並登入的人都可以接受邀請。不要將其張貼在共享管道中。始終傳遞完整的連結：**#** 之後的秘密部分只由瀏覽器讀取，絕不會到達伺服器或其日誌。
- 決定、查證和核准權限絕不會包含在角色包中。只有持有這些權限的管理員才能逐一授予它們。受任命限制的操作（例如拖船或開航決定）還需要營運方任命。授予角色包並不會任命任何人為船長或查證人。
- 您不能核准您本人作為來源方或受託人的委派。委派絕不會超出來源方目前的權限，也絕不會是租戶範圍的。
- POSEIDON 不保存任何密碼，只保留邀請連結的指紋，並且絕不會在清單中回顯 IdP subject。

## 發生問題時
- **This identity is configured by the operator, already a member here or already invited here.**請改為開啟現有成員，或先撤銷舊的邀請。
- **被邀請的人看到「此邀請無法被接受」：**連結已過期、已被使用、已被取代或已被撤銷，屬於另一個帳戶，或其帳戶已屬於某個組織。檢查**Invitation**狀態，必要時按**Create a new invitation link**。
- **連結未被複製：**選取連結欄位並手動複製。
- **Exceeds your own authority：**選擇範圍更窄的角色包或範圍，或請持有該權限的管理員處理。
- **紀錄在此期間已變更：**按**Reload current state**並重新進行變更。
- **The outcome is unknown. Retry with the same request or reload.**您可以安全地重新傳送同一指令。
- **Not the trusted identity provider：**檢查簽發方。如果帳戶來自另一個 IdP，請聯絡系統管理員（13.03 §10）。
