## 本頁用途
「系統健康狀況」在一個畫面上向管理員顯示**服務觀測**：API、稽核寫入器、同步、通知作業、檔案服務和輸入時效性。它回答的問題是：「對於所選船舶和本租戶，觀測到了哪些服務訊號，哪些沒有觀測到？」設定情況和缺漏的遙測資料都不能證明服務健康或船舶就緒。

## 誰使用本頁
- **系統 / 租戶管理員：**發現服務和同步問題，並以受控方式處理（13.03 §9）。
- **支援 / 工程：**在回報應用程式錯誤時審核觀測結果（13.03 §10）。

## 開始之前
- 只有具備租戶範圍讀取、操作歷史讀取和系統健康狀況讀取權限的使用者才能看到本頁。
- 在頂部情境列中檢查是否選擇了**正確的公司**。
- 觀測按船舶請求；您必須先選擇一艘船舶。

## 操作步驟
1. 在**船舶觀測範圍**中選擇船舶。清單較長時，使用**上一頁船舶** / **下一頁船舶**。
2. 檢查「讀取時間」。
3. 在**服務存活狀態**中，閱讀程序啟動時間和運行時長。
4. 在**API**和**稽核寫入器**卡片中，閱讀請求、錯誤、已持久化和延遲數據。這些數據涵蓋本租戶自程序啟動以來的情況。
5. 在**同步**中，查看已提交的結果、未解決的衝突和最近一次已提交的同步。
6. 在**通知作業**中，查看未結通知、已逾期的升級和評估作業狀態。
7. 閱讀**檔案服務**和**輸入時效性**卡片。
8. 在**試點指標**下，審核來自已登記試點用戶端的觀測結果。
9. 按**重新整理觀測**取得目前資料。

## 狀態含義
- **未觀測 / 不可用：**此訊號沒有觀測結果。這並不表示「健康」或「沒有問題」。
- **已設定 · 未探測：**檔案服務看起來已設定，但尚未對儲存體或掃描器進行即時探測。
- **在排程內 / 執行中 / 已逾期 / 排程器未啟用 / 執行已放棄（租約已過期）：**通知評估作業的狀態。
- **未解決衝突：**等待人工解決的離線衝突。它們絕不會被自動合併。
- **目前 / 過時 / 未知 / 不可用：**輸入時效性評估的計數。未知並不表示「目前」。
- **此快照已超過兩分鐘：**在依賴它之前請先重新整理。

## 不能做的事 / 注意
- 本頁為唯讀；不會對服務、船舶或紀錄執行任何操作。
- 通知紀錄僅存在於應用程式內；它們不能證明已送達，也不能證明任何安全決定。
- 服務存活狀態只表明此 API 程序作出了回應；它不能證明其他服務正在運行。
- 試點指標是聲明的且未經查證；它們不是驗收聲明。
- 不要直接在正式環境中修正資料；以受控方式發布設定變更（13.03 §9）。

## 發生問題時
- **此情境無法存取健康狀況：**檢查您的角色和租戶範圍。
- **服務觀測不可用：**不會推斷為健康狀態；稍後使用「重新整理觀測」。
- **存在未解決的衝突：**引導相關使用者前往衝突中心（13.03 §10）。
- **應用程式錯誤：**附上關聯 ID、畫面、時間和操作步驟向支援/工程團隊回報。
