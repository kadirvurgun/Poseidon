## 本頁用途
資料可信中心顯示所選船舶的控制、證據和船舶檔案欄位的**資料品質訊號**。它回答的問題是：「這艘船上哪些紀錄缺漏、過時、相互衝突、未經查證或孤立？是哪些來源和時效性資訊這樣表明的？」可信訊號不是對底層紀錄的查證。本頁絕不會把任何內容標記為就緒。

## 誰使用本頁
- **法規 / 保證使用者：**避免在要求 → 控制 → 證據 → 查證鏈中遺留孤立或不完整的紀錄（13.03 §8）。
- **DPA：**追蹤證據和查證缺口（13.03 §4）。
- **技術主管 / 船長：**查看使就緒評估保持在需要審查狀態的訊號（13.03 §2, §5）。

## 開始之前
- 在頂部情境列中檢查是否選擇了**正確的公司**（13.03 §1）。
- 本頁需要同時具備控制、證據、檔案、適用性和租戶法規草稿讀取權限，並具有租戶範圍的讀取範圍。
- 如果未選擇船舶，本頁會先顯示「請選擇船舶」清單。

## 操作步驟
1. 從「請選擇船舶」清單中選擇船舶。
2. 在**摘要**中，閱讀整體狀態（「需要審查」或「無重要訊號」）以及**各訊號對象數**。
3. 在**控制與證據**表中，檢查每個對象的「來源 / 出處」、「時效性」、「查證」和「訊號」欄。
4. 記下訊號標記旁的原因代碼，並在紀錄自己的頁面上審核該紀錄。
5. 在**船舶檔案欄位**表中查看檔案欄位的訊號。
6. 使用**上一頁** / **下一頁**查看其他對象。
7. 如果出現「這些訊號可能已過期。」，請按**重新載入**。

## 狀態含義
- **缺漏 / 過時 / 衝突 / 未經查證 / 孤立：**對象上的訊號類型。訊號是品質標記；它不能證明紀錄正確或錯誤。
- **無訊號：**在此對象上未發現訊號。這並不表示紀錄已查證。
- **需要審查：**存在重要訊號。存在重要訊號時，就緒狀態保持為需要審查。
- **無重要訊號：**這不是就緒聲明。
- **已人工驗證：**獲授權人員已查證該證據。這來自證據自身的紀錄；本中心不查證任何內容。
- **未查證 / 查證已過期 / 查證被拒絕：**證據的查證狀態。
- **不適用於控制：**顯示在控制列上；查證狀態針對的是證據列。
- **觀測時間未知 / 無時效性政策 / 日期在未來：**無法確定時效性，或日期在未來。這些都不表示「目前有效」。

## 不能做的事 / 注意
- 不能在本頁更正、查證或關閉紀錄；這些操作由獲授權人員在紀錄自己的頁面上進行。
- 如果只評估了前面的部分對象，摘要保持為需要審查。
- 您無法讀取的對象會被計數但不顯示，此時摘要保持為需要審查。您看不到的紀錄並不表示不存在問題。
- 離線時無法重新整理資料可信訊號。

## 發生問題時
- **您無權讀取資料可信訊號：**檢查您的角色和船舶情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **紀錄無法查證：**檢查證據及其出處；向獲授權的查證人提出。
- **非預期的訊號：**向控制負責人或領域專家提出該原因代碼。
- **資料可信訊號不可用：**使用「重試」；如果問題持續，請附上螢幕截圖、時間和您的操作步驟向支援團隊回報。
