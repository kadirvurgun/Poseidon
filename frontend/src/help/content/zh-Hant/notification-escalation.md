## 本頁用途
通知頁面列出所選船舶或拖船的**應用程式內已設定來源異常**（維護到期、維護需要審核、維護來源已變更或不可用）。它回答的問題是：「哪些維護通知送達了我的角色？它們的嚴重程度如何？哪些因無人及時確認而被升級？它們基於哪筆來源紀錄？」確認不會查證證據，也不會核准作業。

## 誰使用本頁
- **輪機長 / 技術主管：**追蹤維護到期日期和審核請求，並轉到來源計畫（13.03 §5）。
- **拖船船長 / 船長 / 船員：**查看傳送給其角色的通知並加以確認（13.03 §6）。

## 開始之前
- 您需要通知、維護和設備讀取權限。確認和儲存偏好需要另外的權限；沒有這些權限時不會顯示相關按鈕。
- 從**通知船舶**中選擇一艘獲授權的船舶或拖船。
- 離線時無法傳送任何確認或偏好指令。

## 操作步驟
1. 從**通知船舶**中選擇船舶。
2. 閱讀政策列：「已設定 · 未經查證的來源政策 · 僅應用程式內送達」。
3. 對每則通知，閱讀標題、嚴重程度標記（**資訊**、**警告**、**嚴重**）和狀態標記；檢查**來源 / 修訂版**、**到期日期**和**建立時間**。**路由規則**顯示規則代碼。
4. 使用**開啟來源計畫**進入相關的維護計畫。
5. 要記錄您已看到某則通知，請按**確認已讀**（僅在**未處理**或**已升級**狀態下）。
6. 如果您有偏好設定權限，請編輯**靜音非強制建議通知**和**勿擾時段**（開始、結束、IANA 時區），然後按**儲存建議偏好**。
7. 使用**上一頁通知** / **更多通知**查看其他頁面，使用**重新載入收件匣**重新讀取。

## 狀態含義
- **未處理：**通知在等待確認。
- **已確認已讀：**有人記錄了自己已看到它。這並不表示維護已完成或證據已查證。
- **已升級：**通知未被及時確認，已按其規則傳送給升級角色。
- **來源已變更 / 來源不可用：**依據紀錄已變更或無法確認。已記錄的依據會被保留；這不會清除或重新啟動通知。
- **強制路由 · 無法靜音：**偏好設定無法將此通知靜音。
- **未知（到期日期）：**來源沒有到期日期。這並不表示沒有到期事項。

## 不能做的事 / 注意
- 確認不會查證證據，也不會核准作業。
- 強制和關鍵路由不能透過建議偏好靜音。勿擾時段只會延後可選通知。
- 頁面為空並不表示一切正常。如果政策或來源不可用，本頁會另行說明。
- 沒有自動重試；不確定的指令會保留在此分頁中，情境變更保持鎖定。

## 發生問題時
- **出現「結果未知」訊息：**使用**重試原通知命令**再次傳送保留的指令。
- **出現「通知版本已變更」訊息：**使用**重新載入收件匣**載入目前清單。
- **出現「通知來源不可用或存取遭拒。」訊息：**檢查您的角色和船舶情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **出現「無法套用已儲存的勿擾時段」訊息：**將顯示所有通知；請檢查您的勿擾時段設定。
