## 本頁用途
重大衝突中心針對所選船舶或拖船，列出**您的離線變更與目前伺服器紀錄之間的實質性衝突**，並讓人以附理由的決定來解決它們。它回答的問題是：「我的哪些離線變更與較新的伺服器紀錄發生了衝突？將如何、由誰、以什麼理由解決？」這裡不會自動覆寫或自動解決任何內容。

## 誰使用本頁
- **船員 / 拖船船長 / 船長 / 輪機長：**在離線工作後查看並解決自己的衝突紀錄。出現衝突時，不要假定自己的紀錄會自動勝出（13.03 §6）。
- 實質性衝突需要人工解決；本頁是 13.03 §10 中「實質性衝突 → 衝突中心」流程的目標頁面。

## 開始之前
- 本頁只列出您記錄的衝突，並且需要至少一個可讀來源的讀取權限（例如船員指派、拖船作業、每日紀錄、工單證據（附設備與維護讀取權限）、證書續期草稿）。任何一個可讀來源都能開啟本頁；所列權限是可替代的。
- 清單和決定需要目前的伺服器連線。離線時，您的本機變更會保留在裝置上。
- 從**船舶**清單中選擇船舶或拖船。

## 操作步驟
1. 從**船舶**中選擇船舶。表格會開啟，包含**來源**、**記錄**、**版本**、**已擷取**、**伺服器接收時間**和**狀態**欄。
2. 如果有「未包含：」提示，說明您沒有讀取權限的來源不在清單中。
3. 在**未決 — 需要決定**的列上，按**審查**。
4. 在**衝突審查**中，比較每個欄位的**擷取之前**、**已擷取**和**伺服器**值。沒有預先選定的選項。
5. 對每個值，明確選擇**保留伺服器值**或**使用擷取值**，填寫**解決原因（必填）**，然後按**提交解決方案**。
6. 若只想刪除此裝置上的本機副本，請在**捨棄我的本機變更**中勾選確認，然後按**捨棄本機變更**。
7. 使用**關閉審查**返回清單。

## 狀態含義
- **未決 — 需要決定：**衝突在等待人工決定。
- **已被較新的衝突取代：**同一紀錄存在較新的衝突；請審查新的衝突。
- **已透過明確決定解決：**有人以附理由的決定解決了它。這不是作業核准。
- **已隱去 / 未提供 / 未知：**該值因授權而被隱藏、未被記錄或無法讀取。未知的值絕不會被視為空或「否」。
- **已為您的明確決定記錄伺服器回執：**伺服器已收到您的決定。此回執不是作業核准。

## 不能做的事 / 注意
- 衝突絕不會被自動合併或解決；每個值都需要明確的人工選擇和理由（13.03 §1）。
- 本中心直接解決船員指派衝突。對於其他來源，它會顯示「請從所屬紀錄的離線面板解決此衝突。」；例如拖船紀錄在**拖船離線作業**中解決。
- 捨棄本機變更只會刪除裝置上的副本；伺服器紀錄不變，衝突會一直保持記錄，直到作出附理由的決定。
- 在另一台裝置上擷取的變更必須在該裝置上解決；不會捨棄任何內容。
- 提交會重新檢查您的存取權限和紀錄版本；它不授予作業核准。

## 發生問題時
- **出現「提交結果未知」訊息：**在再次提交之前，請使用**檢查提交結果**。
- **出現「伺服器紀錄在您審查後已變更」 / 「伺服器紀錄再次變更」訊息：**您的決定未被套用；請重新審查該衝突。
- **「無法載入實質性衝突。未解決任何內容。」：**按**重試**。
- **「您無權存取衝突中心。」 / 「此船舶的衝突存取不可用。」：**檢查您的角色和船舶情境；必要時聯絡您的租戶管理員（13.03 §10）。
