## 本頁用途
本頁以唯讀方式顯示拖船指派在計畫時間窗口內的**船員與拖帶能力**檢查。它回答的問題是：「對於此指派的船員，最低安全配員（MSMD）、證書與能力以及工作/休息檢查的結論是什麼？它們來自哪個來源？」結果僅為建議，並輸入到就緒關卡；它不是資格核准，也不是 GO 決定。

## 誰使用本頁
- **拖船船長：**綜合評估 MSMD、證書、能力、熟悉訓練和工作/休息情況，以判斷船員就緒（13.03 §3）。
- **拖船作業協調員 / 岸上營運：**追蹤某個指派的船員阻礙項目（13.03 §7）。

## 開始之前
- 從指派開啟本頁：在**指派與衝突**中，使用某個方案下的**船員與拖帶能力**連結。未選擇指派時，本頁顯示「請從任務的指派清單中選擇一個指派。」
- 除拖船讀取權限外，您還需要船員、人工審核和適用性讀取權限；否則無法讀取受保護的船員來源。
- 指派需要一個有效的目前或未來時間窗口；否則結果需要審核。

## 操作步驟
1. 在**狀態**列閱讀整體結果。
2. 在**船員資格評估器**列，查看評估器是否已連接及其來源。
3. 在檢查表中，閱讀每一列的**類別**、**結果**和**原因代碼**。
4. 如果存在阻礙項目或審核原因，請將船員紀錄轉交給其負責人；然後返回**作業就緒關卡**。

## 狀態含義
- **就緒 / 有條件 / 未就緒 / 需要審查：**建議性評估。就緒不是 GO 決定。
- **未連接——所有拖輪專屬標準均保持待審查。：**評估器未連接；拖船專屬標準保持需要審查，不計為就緒。
- **通過 / 未通過 / 未知：**單項檢查的結果。關鍵缺口絕不會顯示為綠色。
- **未知：**來源缺失或無法讀取。未知的檢查需要審核；它絕不能代替「就緒」或「否」。

## 不能做的事 / 注意
- 本頁不變更任何船員紀錄，也不核准任何資格。
- 結果只是建議；作業決定始終由拖船船長作出，岸上指派絕不能推翻該決定（13.03 §3, §7）。
- 不要變更他人已查證的紀錄；更正屬於紀錄負責人（13.03 §6）。

## 發生問題時
- **「您無權存取此紀錄。」：**檢查您的角色、拖船和物件情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **「服務無法使用。」：**按**重試**。
- **非預期的就緒結果：**記下原因代碼，並與控制負責人或領域專家一起審核（13.03 §10）。
- **紀錄無法查證：**檢查證書和證據來源；聯絡查證人（13.03 §10）。
