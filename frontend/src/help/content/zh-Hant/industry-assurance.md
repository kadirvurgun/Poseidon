## 本頁用途
「產業保證」頁面從活頁簿匯入油輪的 SIRE 2.0 檢查結果，將變更提交人工審查，把發現事項連結到安全措施，並記錄現場證據。它回答的問題是：「這次檢查的哪些發現事項尚未關閉？哪些已連結措施？證據在哪裡？」匯入是草稿：每個變更的項目都由另一人接受。發現事項保持未關閉且未經查證；本頁絕不會關閉或查證它們。鏈條是發現事項 → 措施 → 查證，查證和有效性是「安全事件與未遂事件」中針對措施的獨立人工紀錄（13.03 §4, §8）。

## 誰使用本頁
- **DPA / HSEQ：**將檢查發現事項連結到措施，並追蹤發現事項 → 措施 → 查證鏈（13.03 §4）。
- **法規 / 保證使用者：**管理欄位對應，準備或審查匯入（13.03 §8）。
- **船長和船上人員：**為發現事項記錄現場證據（照片）。

## 開始之前
- 選擇船舶。SIRE 2.0 僅適用於油輪。如果船舶檔案中未聲明船舶類型，匯入保持**需要審查**。
- 讀取需要檢查讀取權限。匯入、接受匯入、寫入證據、連結發現事項和撰寫對應都是另外的權限。連結措施還需要安全事件讀取權限；記錄證據還需要檔案讀取權限。
- 欄位結構是合成的；未使用獲授權的 OCIMF 格式。
- 離線時只有照片擷取會在此裝置上排入佇列；匯入和決定需要網路連線。

## 操作步驟
1. **選擇船舶**並檢查**適用性**列。
2. 必要時，在**欄位對應**中輸入**對應鍵**，每欄寫一行（標頭=欄位），然後按**另存為新版本**。
3. 在**準備匯入**中選擇**對應版本**、**檢查編號**、**檢查日期**和**活頁簿（.xlsx）**，然後按**提交審查**。
4. 由另一人在**匯入審查**中為每個變更的項目選擇**接受**或**保留目前值**，寫下至少 10 個字元的**理由**，然後按**接受匯入**或**拒絕匯入**。
5. 從**檢查**清單中開啟一次檢查。審核**項目**和**發現事項**。
6. 要將發現事項連結到措施，請輸入**安全措施 ID**並按**關聯措施**。
7. 對於現場證據，請輸入**媒體**、**乾淨檔案 ID**、**檔案修訂**和**檔案總和檢查碼（SHA-256）**，然後按**記錄現場證據**。離線時該按鈕變為**儲存到本裝置**；連線後使用**立即傳送**傳送。

## 狀態含義
- **油輪：適用 / 不適用 / 船舶類型未知：需要審查：**船舶類型未知時，結果保持**需要審查**；絕不會被假定為不適用。
- **等待審查 / 已接受 / 已拒絕：**匯入狀態。
- **新增 / 已變更 / 未變更 / 不在此次匯入中：**與上一次已接受的匯入相比的項目狀態。不在此次匯入中的項目為**保留（從不刪除）**。
- **負面觀察 / 正面觀察 / 無觀察 / 未知：**項目上的觀察。
- **未關閉 / 未經查證：**此處的發現事項始終顯示為未關閉且未經查證。
- **未連結措施 / 已連結措施：**發現事項是否連結到安全措施。已連結措施並不表示發現事項已查證或措施有效。
- **線上擷取 / 離線擷取：**證據的擷取方式。

## 不能做的事 / 注意
- 準備匯入的人不能審查它：「您準備了此匯入；必須由其他人審查。」
- 本頁不關閉也不查證發現事項。已查證不等於有效；有效性是針對措施的另外的人工審查。
- 在營運方啟用經掃描的影片檔案類型之前，影片證據不可用。
- 後續匯入中缺少的項目絕不會被刪除；歷史會被保留。

## 發生問題時
- **請求被拒絕：**解決其下方列出的原因。
- **紀錄已在此期間變更。請重新載入並再次審查。**按**重新載入**。
- **結果未知（連線中斷）。**使用**重試同一請求**。
- **您無權讀取產業保證紀錄。**或**您無權執行此操作。**檢查您的角色和船舶情境；必要時聯絡租戶管理員（13.03 §10）。
- 如果證據無法查證，請檢查檔案 ID、修訂版本和 SHA-256 總和檢查碼；必要時聯絡查證人（13.03 §10）。
