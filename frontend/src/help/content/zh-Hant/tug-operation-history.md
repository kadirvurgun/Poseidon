## 本頁用途
作業歷史顯示拖船任務、執行、每日日誌和證據的**唯讀歷史**。它回答的問題是：「哪些任務以什麼結果結束？執行是否已查證？是否有證據紀錄？哪些每日日誌屬於這些任務？」已取消和已中止的紀錄始終可見；不會刪除任何內容，也不會重新標記。

## 誰使用本頁
- **拖船作業協調員 / 岸上營運：**追蹤已完成任務的證據完整性、事件和歷史紀錄（13.03 §7）。
- **拖船船長：**查看本拖船過去的任務和執行時間軸（13.03 §3）。

## 開始之前
- 從**拖船作業**開啟拖船；未選擇拖船時，本頁顯示「請選擇一艘拖船以繼續。」
- 拖船讀取權限即可；本頁不變更任何資料。
- 歷史從伺服器讀取；離線時無法重新整理。

## 操作步驟
1. 在**篩選條件**中，可選擇設定**拖船 ID**、**起始(UTC 日期)**、**截止(UTC 日期)**和**結果**，然後按**套用篩選**。日期範圍最多 400 天。
2. 在表格的每一列中，閱讀**任務**（任務編號、被協助船舶、任務類型、計畫和簡報狀態）、**活動時間**、**結果**和**證據**。
3. 在**執行**中，查看每次執行的狀態、查證狀態、持續時間、船長紀錄和證據項目數量；使用**開啟執行時間軸**進入執行控制台。
4. 使用**每日日誌**中的連結開啟相關日誌。「日誌未連結」的附註表示該日誌沒有連結此次執行。
5. 使用**載入更多**查看較早的紀錄。**讀取時間**顯示資料的讀取時間。

## 狀態含義
- **未開始 / 進行中 / 已完成(已記錄) / 已中止 / 已取消 / 混合：**任務的整體結果。已完成(已記錄)並不表示任務已查證。
- **已查證，證據已記錄 / 已查證，無證據項目 / 查核被拒絕 / 證據未查核 / 未知：**證據和查證狀態。
- **查核待定 / 已查證 / 查核被拒絕：**單次執行的查證狀態。
- **無：**此任務不存在連結的紀錄。這並不表示不需要紀錄。

## 不能做的事 / 注意
- 本頁不編輯、不刪除、也不查證任何紀錄。
- 不會靜默刪除：已取消的任務以及已中止或被拒絕的執行都保留在歷史中。
- 已完成 ≠ 已查證：查證是另一人的紀錄。
- 顯示的資料是**讀取時間**時的狀態；離線時不會重新整理。

## 發生問題時
- **出現「篩選條件無效」訊息：**檢查拖船 ID 是否為 UUID，以及日期範圍是否超過 400 天。
- **出現「無法載入歷史。」訊息：**檢查您的網路連線並按**重試**。
- **「您無權存取此拖船範圍。」：**檢查您的角色和拖船情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **紀錄無法查證：**在執行時間軸中檢查證據參照及其來源；聯絡查證人（13.03 §10）。
