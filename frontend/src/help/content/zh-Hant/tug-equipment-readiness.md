## 本頁用途
本頁顯示所選拖船的**拖帶設備聲明**（拖纜絞車、拖鉤、拖纜、緊急釋放裝置、消防 FiFi）及其**輪機長核驗**。它回答的問題是：「每一項的 SWL、試驗日期、狀況和關鍵性是什麼？由誰查證？就緒檢查的結論是什麼？」評估僅為建議，並輸入到就緒關卡；它不是 GO 決定。

## 誰使用本頁
- **拖船船長：**檢查絞車、拖纜、拖鉤 / 鏈制動器、緊急釋放裝置、FiFi 以及關鍵缺陷證據（13.03 §3）。
- **輪機長：**對聲明作出已查證或未查證的紀錄，並記錄關鍵缺陷對就緒的影響（13.03 §5）。

## 開始之前
- 從**拖船作業**開啟拖船；本畫面不需要指派。
- 新增或編輯聲明需要拖船寫入和設備寫入權限。
- 記錄查證需要伺服器中已記錄的該拖船**輪機長**任命。

## 操作步驟
1. 在**評估**列閱讀整體標記。
2. 在每張設備卡片上，檢查結果標記、原因代碼、**安全工作負荷 (t)**、**下次試驗到期**、**狀況**和**關鍵**。
3. 對於新聲明，按**新增設備**；填寫**設備類型**、**標籤**、**安全工作負荷 (t)**、**上次試驗**、**下次試驗到期**、**狀況**、**關鍵**、**PMS 資產 ID**、**證書 ID**和**備註**，然後按**儲存聲明**。
4. 要變更現有聲明，請使用其卡片上的**編輯**。
5. 作為輪機長，選擇您的**任命**，寫下理由，並使用**已驗證**或**未驗證**來**記錄驗證**。選擇「未驗證」時必須填寫理由。
6. 在**輪機長核驗**下查看附修訂版本和時間的查證歷史，並查看底部的**來源檢查**表。

## 狀態含義
- **就緒 / 有條件 / 未就緒 / 需要審查：**建議性評估。就緒不是 GO 決定。
- **通過 / 未通過 / 未知：**單項的檢查結果。
- **可用 / 降級 / 故障 / 未知：**聲明的狀況。如果未選擇狀況，則保持「未知」；它不會被計為可用。
- **未評估：**尚未評估關鍵性。這並不表示「否」。
- **已驗證 / 未驗證：**輪機長的人工紀錄。
- **已被後續修訂取代：**該查證屬於聲明的較早修訂版本；目前修訂版本需要新的查證。

## 不能做的事 / 注意
- 儲存只會記錄一份未經查證的聲明。任何變更都需要輪機長重新查證。
- 完成紀錄與查證紀錄不是同一個操作；查證需等待獲授權人員（13.03 §1）。
- 儲存後不能變更設備類型；如需其他類型，請新增新的聲明。
- 本頁絕不會宣告拖帶設備安全；該決定始終由拖船船長作出（13.03 §3）。
- 離線時指令被停用。

## 發生問題時
- **出現「紀錄已變更」訊息：**使用**重新載入**查看目前聲明。
- **出現「結果不確定」訊息：****重試**會傳送同一指令。
- **紀錄無法查證：**檢查證據以及 PMS/證書來源；聯絡查證人（13.03 §10）。
- **未獲授權：**檢查您的角色、拖船和任命情境；必要時聯絡您的租戶管理員（13.03 §10）。
