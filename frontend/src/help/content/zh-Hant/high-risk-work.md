## 本頁用途
「高風險作業」頁面在一個**唯讀**清單中顯示船隊作業（如動火作業、密閉空間、高處作業、電氣隔離、關鍵維護、拖帶和加油作業）的異常。它回答的問題是：「哪項高風險作業在風險、許可、關鍵屏障、船員或設備方面存在未決問題？由誰負責下一步措施？」每個維度分別顯示；沒有彙總評分。操作會開啟所屬紀錄；本頁不變更任何紀錄，也不作出開始作業的決定（13.03 §4）。

## 誰使用本頁
- **DPA / HSEQ：**作為風險治理的一部分，關注整個船隊的高風險作業異常（13.03 §4）。
- **船長和拖船船長：**查看本船高風險作業的阻礙項目，並進入所屬紀錄。開始或停止作業的決定始終由他們作出（13.03 §2, §3）。

## 開始之前
- 檢視需要風險讀取和高風險作業讀取權限。沒有這些權限時您會看到「您無權存取高風險作業檢視。」
- 清單只涵蓋您範圍內的船隊和船舶。
- 離線時顯示的清單可能已過期。

## 操作步驟
1. 選擇**船隊**、**船舶**和**作業類型**篩選條件。**全部**會移除篩選條件。
2. 在表格中分別閱讀每項作業的**風險**、**許可**、**關鍵屏障**、**船員**和**設備**狀態。**關鍵阻斷項**和**待審核項**標記顯示數量。
3. 使用**下一步措施**和**負責人 / 到期**欄查看誰需要做什麼。
4. 要查看某一列為何處於該狀態，請按**原因**。會開啟一個包含**維度**、**狀態**和**理由**的表格；使用**隱藏**關閉。
5. 要進行任何變更，請透過作業連結或**開啟記錄**；操作在所屬紀錄自己的頁面上進行。
6. 使用**上一頁**和**下一頁**翻頁。**評估時間**和**來源涵蓋範圍**顯示清單是何時、根據哪些來源計算的。

## 狀態含義
- **就緒 / 有條件 / 關注 / 未就緒 / 受阻：**該維度在其來源中的狀態。某個維度為就緒並不表示作業可以開始；決定始終由獲授權人員作出。
- **需要審查：**需要有人審核。
- **未知：**來源不可用；它絕不是就緒。POSEIDON 目前還沒有作業許可來源，因此**許可**欄始終顯示**未知**。
- **正常 / 降級 / 故障：**關鍵屏障的狀態。
- **未分類：**作業類型未知或其關鍵性尚未確定；它不會被排除在清單之外。
- **等待來源 / 解決停止或爭議 / 更新已過期項目 / 完成必要項目 / 重新評估 / 開啟負責人紀錄：**下一步措施，按固定的優先順序顯示。
- **到期未確定 / 未計畫：**到期日期或計畫開始時間未知。

## 不能做的事 / 注意
- 本頁為唯讀；它不變更、不核准、也不許可任何事項。
- 沒有彙總評分；存在關鍵阻斷項的作業始終排在最前面，其他維度正常也絕不會掩蓋它。
- 不要把**未知**理解為就緒。歷史上的有效許可絕不是目前有效的許可。
- 開始或停止作業的決定始終由船長或拖船船長作出。

## 發生問題時
- **服務無法使用。請重試。**按**重試**。
- **您已離線。顯示的清單可能已過期。**連線後按**重新載入**。
- 如果某個狀態看起來出乎意料，請開啟**原因**表格，並詢問紀錄負責人或控制負責人（13.03 §10）。
- 如果沒有存取權限，請檢查您的角色和船舶情境；必要時聯絡租戶管理員（13.03 §10）。
