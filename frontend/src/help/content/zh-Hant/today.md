## 本頁用途
「今天」頁面針對您所選的船舶或拖船，把**現在需要您關注的警示**彙整在一個清單中。它回答的問題是：「這艘船上的哪筆紀錄今天在等待決定或檢查？是哪個來源這樣說的？」本頁不做任何決定；它只顯示警示、警示的來源和下一步。

## 誰使用本頁
- **船長**和**拖船船長：**查看當天的例外情況、其負責人和下一步（13.03 §2, §3）。
- **輪機長：**追蹤維護計畫警示（13.03 §5）。
- **Crew / OOW：**查看分派給自己的工作（13.03 §6）。

## 開始之前
- 在頂部情境列中確認已選擇**正確的公司和船舶**（13.03 §1）。您看到的警示屬於所選船舶。
- 您需要工作區的讀取權限才能開啟本頁。
- 如果未選擇船舶，本頁會先顯示「選擇船舶」清單。

## 操作步驟
1. 選擇您正在處理的船舶或拖船。所選船舶顯示為「目前船舶」；使用「切換船舶」可變更。
2. 查看頂部的**來源涵蓋範圍**區段。它顯示哪些來源（法規、計畫維護、拖船作業）能夠被讀取。
3. 由上到下閱讀警示卡片。每張卡片來自一個來源，並建議下一步（例如「審核草稿」「審核維護計畫」「檢視拖船任務」）。
4. 按**原因？**查看卡片背後的理由。該區段顯示規則、來源紀錄、其修訂版本、讀取時間以及所有未知輸入。
5. 透過卡片的連結進入該紀錄自己的頁面，並在您的權限範圍內在那裡操作。
6. 使用**重新整理**重新讀取資料。

## 狀態含義
- **可用（未經查證）：**已讀取該來源。這並不表示其內容已經過查證。
- **缺失 / 在此情境下不可用：**無法為這艘船讀取該來源。您看不到的警示並不表示一切正常。
- **部分檢視：**部分來源無法讀取。數量為零並不表示「沒有問題」。
- **所列來源均已讀取且未傳回任何項目：**沒有傳回警示。這不是安全放行。
- **未知：**來源中缺少該值，或無法確定該值。未知不等於「否」、「就緒」或「不適用」。
- **需要審查 / 計畫關注事項 / 建議：**卡片的優先順序。需要審查的卡片在等待獲授權人員查看。
- **已完成 ≠ 已查證：**紀錄已完成並不表示獲授權的查證人已確認它（13.03 §1）。

## 不能做的事 / 注意
- 本頁不做離港、作業或安全決定。該決定屬於獲授權的船長或拖船船長。
- 本頁不執行任何指令；操作在紀錄自己的頁面上進行。
- 離線時顯示的資料是舊的且未經查證。離線時無法開啟「原因？」詳細資訊。
- 讀取時間或儲存時間不能證明來源是正確的。

## 發生問題時
- **離線：**繼續您的關鍵工作並留意同步狀態。如果出現衝突，請前往衝突中心（13.03 §10）。
- **存取遭拒 / 船舶不在您的存取範圍內：**檢查您的角色和船舶情境；必要時聯絡您的租戶管理員。
- **非預期的警示：**開啟「原因？」；如果規則或來源看起來有誤，請轉交給控制負責人或領域專家。
- **來源不可用 / 請求過多：**稍候片刻後使用「重試」。
- **伺服器回應未通過驗證：**不會顯示其中的任何內容；請附上螢幕截圖、時間和您的操作步驟向支援團隊回報。
