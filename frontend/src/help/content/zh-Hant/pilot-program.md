## 本頁用途
「試點計畫」頁面將一艘船舶（以及可選的一艘拖船）的試點週次、每週的檢查項目、試點問題、每日回饋和價值報告集中在一處。它回答的問題是：「每個試點週次的檢查項目是否都已由真實紀錄滿足？量測值相對於基線有何變化？」頂部的提示適用：「軟體不能完成試點。只有當您將檢查項目連結到經伺服器查證的真實紀錄時，該檢查項目才算滿足；缺漏的基線保持未知；只有被任命的產品負責人才能關閉週次或記錄計畫決定。」

## 誰使用本頁
- **產品負責人：**關閉週次並記錄計畫決定（繼續、修復、停止、擴大）。這需要目前的產品負責人任命。
- **試點團隊：**將紀錄連結到檢查項目，回報問題，記錄回饋和量測。
- **分類負責人：**對問題進行分類並解決。
- 13.03 沒有為本頁定義另外的角色；適用租戶管理原則（13.03 §9）。

## 開始之前
- 檢視需要租戶範圍讀取和試點計畫讀取權限。建立計畫、記錄、分類和決定各自需要另外的權限；關閉週次和作出決定還需要產品負責人任命。
- 您連結的紀錄（例如證書、船員或工單紀錄）必須已在其各自的頁面上存在。
- 在回饋中切勿輸入姓名、電子郵件地址、電話或證件號碼；只使用化名和角色。
- 記錄需要即時連線。

## 操作步驟
1. 從**試點計畫**中開啟一個計畫。對於新計畫，請在**建立試點計畫**中填寫**計畫名稱**、**船舶**、**拖船（選填）**、**第 1 週開始日期**和**日曆時區（IANA）**，然後按**記錄**。
2. 在每個**週**區段中，審核**檢查項目**、**準則（來源）**、**範圍**、**狀態**和**已連結紀錄**欄。
3. 要滿足某個檢查項目，請在**連結紀錄**中輸入**檢查項目**、**紀錄類型**和**紀錄識別碼**，然後按**連結紀錄**。寫下**撤回原因**後，使用**撤回連結**移除錯誤的連結。
4. 在**試點問題**中，使用**回報問題**輸入範圍、**類別**、嚴重程度和**問題摘要**。分類負責人使用**初步分級**並填寫**分類備註**，然後解決問題。
5. 在**每日回饋**中，使用**記錄回饋**輸入**摘要**和**感受**。
6. 在**價值報告**中，使用**記錄量測**輸入**指標**、**階段**（基線或試點期間）、**數值**、**樣本數量**、**期間起**、**期間迄**、**證據參考**和**方法與樣本**。
7. 如果您是產品負責人，請在**關閉本週**中記錄結果和理由。計畫結束時，在**記錄計畫決定**中填寫決定、**任命**和**理由**，然後按**記錄**。

## 狀態含義
- **已連結並驗證：**一筆經伺服器查證的真實紀錄已連結到該檢查項目。**連結已失效**和**缺漏**的檢查項目未被滿足。
- **需要完成：**連結的紀錄必須處於已完成狀態。「稽核軌跡證明有人撰寫了該紀錄；它不能證明紀錄或流程已完成。」
- **可供人工關閉 / 未就緒：**對該週的建議；只有產品負責人才能將其關閉為**已接受**或**未接受**。
- **當日已分類 / 分類延遲 / 今日應分類 / 已逾期：**P0 問題相對於計畫日曆日的分類時間。對於**來源未規定當日目標**的問題，系統不會自行設定截止時間。
- **已量測 / 未知：**當基線值或試點值缺漏時，報告保持**未知**；它絕不會被計為零或改善。**不可比較**的值不會進行比較。
- **遙測（已申報，未驗證）：**聲明的遙測值。
- **符合擴大條件；待人工決定 / 建議修復：**計畫建議，不是決定。

## 不能做的事 / 注意
- 「只有當每個檢查項目都已查證且沒有未關閉、待處理或延遲的 P0 分類時，才可能為已接受。」
- 「只有當每個週次都已接受，且數值、UAT、缺陷和 P0 都沒有問題時，才可能擴大。」
- 如果某個週次或決定所依據的證據（連結、回饋、量測）是您撰寫的，您不能關閉該週次或記錄該決定。
- 虛構資料計畫不能記錄週次關閉或決定。
- 系統絕不會完成試點，絕不會關閉週次，也絕不會偽造決定或簽署。

## 發生問題時
- **您目前沒有產品負責人任命；週關閉與決定為唯讀。**請聯絡租戶管理員取得任命（13.03 §10）。
- **在維運人員設定保存政策之前，無法收集回饋。**請系統管理員設定保存政策。
- **記錄已變更或已被使用。請重新載入。**使用**重新載入**開啟目前狀態。
- **結果不確定。重試將送出相同命令。**使用**重試**安全地重新傳送同一指令。
- **遭規則拒絕。**例如，連結的紀錄可能不存在、超出範圍或尚未完成。
- **不允許。**此週次關閉或決定所依據的連結、回饋或量測是您撰寫的；必須由另一人記錄。
- 尚未開始的週次不能關閉（顯示為「記錄已變更或已被使用。請重新載入。」）。
- **您無權存取這些記錄。**檢查您的角色和租戶範圍（13.03 §10）。
