## 本頁用途
拖船日誌針對一個日期和值班記錄**任務、主機運轉計數器、燃油和缺陷**，並將其與當天的拖帶作業執行進行**核對**。它回答的問題是：「這一天/這個值班完成了多少個任務？計數器時數是否與執行時間相符？使用了多少燃油？回報了哪些缺陷？」核對結果僅為建議；船長審核是另外的人工紀錄。

## 誰使用本頁
- **船員 / 值班人員：**即時並按順序保持值班紀錄（13.03 §6）。
- **拖船船長 / 船長：**審核已提交的日誌，並查證或退回（13.03 §3）。

## 開始之前
- 從**拖船作業**開啟拖船。
- 建立和編輯日誌需要拖船寫入權限。
- 審核需要伺服器中已記錄的該拖船**任命**（拖船船長或船長）。撰寫或提交日誌的人不能審核它。

## 操作步驟
1. 從清單中開啟現有日誌，或選擇**日誌日期**和**值班**後按**建立日誌**。
2. 輸入**時區 (IANA)**。
3. 在**主機運轉時數計數器**中，為每個**計數器**輸入**起始讀數**、**結束讀數**，必要時輸入**歸零或溢位翻轉證據**。
4. 在**燃油消耗**中，輸入數值、單位和**燃油來源參考**。
5. 在**當日拖帶作業執行**中勾選屬於此日誌的執行；填寫連結的缺陷識別碼和**每日摘要**（摘要至少 20 個字元）。
6. 按**儲存**。在**核對**列上，檢查已完成的任務、執行時數、計數器時數和已回報的缺陷。
7. 當**阻礙項目**清單為空時，按**提交船長審核**。
8. 作為船長，選擇您的**任命**，寫下理由，然後按**船長：核驗日誌**或**船長：退回日誌**。

## 狀態含義
- **草稿 / 已提交 / 已退回 / 已查證：**日誌狀態。
- **船長審核 — 待處理 / 關注 / 已審核：**待處理 = 等待審核；關注 = 已退回，或在核對結果不是「已核對」時提交；已審核 = 已由船長查證。已提交的日誌不是已查證的日誌。
- **已核對 / 需要審查 / 不完整：**建議性的比較結果。原因代碼列在其下方。
- **未結束區間：**某次執行仍在進行中；執行時數尚未最終確定。
- **安全事件 — 未知：**本頁不統計安全事件；不會得出「沒有事件」的結論。
- **已同步 / 等待同步 / 衝突 / 失敗：**同步狀態。等待同步表示變更尚未到達伺服器。

## 不能做的事 / 注意
- 撰寫日誌或將其提交船長審核的人不能查證它。
- 核對結果不是核准；由船長進行審核。
- 完成紀錄與查證紀錄不是同一個操作（13.03 §1）。
- 離線時，一項未儲存的變更會保留在此頁面的記憶體中，並在網路連線恢復時以其原始鍵傳送；請保持頁面開啟。提交和審核在線上進行。
- 如果出現衝突，不要假定您自己的紀錄會自動勝出（13.03 §6）。

## 發生問題時
- **出現「伺服器列出了缺漏或阻礙的項目。」訊息：**清除**阻礙項目**中的代碼。
- **出現「紀錄已變更或指令衝突。」訊息：**使用**重新載入最新版本**審核目前日誌；保留的本機變更會被捨棄。
- **出現「結果未知。」訊息：****重試**會再次傳送完全相同的指令。
- **衝突：**保留在此頁面上的變更絕不會被合併；請使用**重新載入最新版本**。在**拖船離線作業**中擷取且發生衝突的每日條目在該處解決；它們也會列在**重大衝突中心**中（13.03 §10）。
