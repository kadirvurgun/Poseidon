## 本頁用途
PMS 指揮中心在一個畫面上彙整所選船舶的維護**異常**。它回答的問題是：「這艘船是否有逾期關鍵作業、未結工單、缺陷警示或關鍵備品缺口？原因是什麼？」本頁是建議性的異常檢視；它不是適航、就緒或安全決定。正常的項目不會列出，只會計數。

## 誰使用本頁
- **輪機長 / 技術主管：**追蹤逾期作業、未結工單、缺陷警示和關鍵備品缺口（13.03 §5）。
- **船長：**查看 PMS 和缺陷紀錄對作業限制的影響（13.03 §2）。

## 開始之前
- 您需要設備讀取權限（`equipment.read`）才能查看本頁。
- 每個區段取決於其所屬模組的讀取權限。例如，沒有缺陷讀取權限時，**狀態警示**區段保持為「需要存取權限：未顯示」。
- 請先選擇船舶。未選擇船舶時，本頁只顯示**請選擇船舶。**清單。

## 操作步驟
1. 從清單中選擇船舶。如果您的範圍內沒有船舶，本頁會顯示「您的範圍內沒有船舶。」
2. 閱讀頂部的**異常摘要**標記和**上次重新整理**時間。
3. 審核各區段：**逾期關鍵作業**、**到期、逾期及待複核作業**、**未結工單**、**狀態警示**和**關鍵備件缺口**。
4. 開啟某一項目的**原因**，查看記錄的原因代碼以及（如有）**觀察於**時間。
5. 使用**開啟來源記錄**進入來源。缺陷項目會開啟[缺陷與臨時措施](/app/defects)，工單項目會開啟[工單中心](/app/work-order-center)。
6. 按**重新整理**重新讀取資料。

## 狀態含義
- **受阻 / 需要審查 / 關注：**異常摘要的狀態。詳細資訊見各區段的項目。
- **無未結異常（建議性）：**已讀取的來源沒有傳回未結異常。這不是就緒或適航結果。
- **關鍵 / 關注 / 需要審查：**項目的嚴重程度。
- **來源不可用：未知，而非零：**無法讀取該區段的來源。未知不等於「零」、「沒有問題」或「就緒」。
- **需要存取權限：未顯示：**您沒有此區段的權限；既不顯示內容，也不顯示數量。
- **此來源無異常：**已讀取該區段，未傳回異常。正常項目的數量另行顯示。
- **資料過時 / 時效性未知：**項目背後的讀數不是最新的，或其時效性未知。

## 不能做的事 / 注意
- 本頁不變更任何紀錄；它只讀取。工單、缺陷和備品在各自的頁面上處理。
- 本頁絕不會宣告船舶「就緒」或「安全」。離港決定屬於船長（13.03 §2）。
- 缺陷只有透過人工關閉紀錄才算關閉，並且只針對被關閉的聲明修訂版本。如果聲明之後發生變更，該項目會回到審核狀態。
- 離線時顯示的資料可能是舊的，且**重新整理**不可用。

## 發生問題時
- **無法載入紀錄：**檢查您的網路連線並使用**重新載入**。
- **您沒有此操作或紀錄的伺服器權限：**檢查您的角色和船舶情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **非預期的異常：**開啟**原因**，並與責任負責人或領域專家一起審核來源紀錄（13.03 §10）。
- **應用程式錯誤：**向支援團隊回報關聯 ID、畫面、時間和操作步驟（13.03 §10）。
