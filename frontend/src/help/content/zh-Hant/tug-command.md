## 本頁用途
本頁在選單中顯示為**拖船指揮**，顯示所選拖船的**來源情境**。它回答的問題是：「這艘拖船記錄了哪些角色、類型、繫柱拖力（BP）和設備聲明？它們來自哪裡，有多新？」本頁只顯示聲明及其來源；它不提供作業就緒、資格、許可或安全核准。頂部的標記也這樣說明：「來源聲明 · 作業就緒情況未知」。

## 誰使用本頁
- **拖船船長：**在開始工作前確認本拖船的角色、BP 和設備情境（13.03 §3）。
- **拖船作業協調員 / 岸上營運：**在進入任務看板和任務受理之前，確保處於正確的拖船情境中（13.03 §7）。
- **船員：**查看自己的角色檢視以及向其開放的船舶模式畫面（13.03 §6）。

## 開始之前
- 您需要拖船模式和拖船讀取權限。沒有這些權限時，本頁顯示「無法存取。」
- 如果未選擇情境，本頁會在**選擇拖船**下列出獲授權的拖船；開啟其中一艘。
- 設備清單還需要設備讀取權限；沒有該權限時，設備來源顯示為「不可用或未授予」。

## 操作步驟
1. 從**選擇拖船**清單中開啟拖船。標題下方的**拖船情境**列顯示拖船代碼、名稱和模式。
2. 在**角色（伺服器指派）**和**拖船模式選單檢視**中，閱讀伺服器為您指派的角色和選單檢視。
3. 在**模式可見性**中，查看船舶模式畫面是否開放。**船舶模式畫面**區段只連結到授予您的畫面。
4. 從**拖船類型**、**類型來源 / 修訂版**和**類型來源觀測 / 策略**中檢查類型來自哪個來源和修訂版本。
5. 閱讀**檔案 BP（未經查證）**、**BP 來源 / 版本 / 溯源資訊**和**BP 時效性 / 觀測**。這是聲明值，不是測量值。
6. 在**設備情境**中，查看設備聲明、其等級、修訂版本和溯源資訊。
7. 使用頁面分頁進入**任務看板**或（有寫入權限時）**任務受理**，或（有寫入權限時）按**新增請求**。

## 狀態含義
- **未知 — 無角色指派：**伺服器中沒有您在這艘拖船上的角色指派。這不是「沒有角色，也沒有問題」；需要管理員進行指派。
- **角色標籤不可用 / 選單檢視不可用：**目前無法讀取來源。缺漏的資訊不會被視為空。
- **未為拖船模式設定檢視：**在此模式下沒有為您定義選單檢視。
- **在拖船模式下隱藏。需要跨模式角色。：**船舶模式畫面需要明確授權的跨模式角色。
- **檔案 BP（未經查證）：**聲明的繫柱拖力。它不是經查證的試驗結果。
- **未傳回設備聲明。經查證的作業適用性仍未知。：**空清單絕不表示設備適用。
- **未知 / 不可用：**來源值缺漏或無法讀取。未知絕不能代替「就緒」或「否」。

## 不能做的事 / 注意
- 本頁不編輯任何欄位，也不產生任何就緒結果。作業決定和安全權限始終屬於船上的拖船船長（13.03 §3）。
- 岸上指派提議絕不能推翻拖船船長在船上的安全決定（13.03 §7）。
- 即使有聲明的跨模式權限，每個船舶模式畫面仍需要其自身的伺服器授權。
- 離線時不顯示目前的檔案來源；請重新連線以重新檢查存取權限和來源版本。

## 發生問題時
- **無法存取：**檢查您的角色、拖船和物件情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **出現「必須檢查目前身分和船舶存取權限」警示：**按**重新檢查存取權限**。
- **資料不可用：**檢查您的網路連線並按**重試**。
- **非預期的 BP 或設備值：**記下來源和版本欄位，並與來源負責人一起審核；如果紀錄無法查證，請檢查其證據和溯源資訊（13.03 §10）。
