## 本頁用途
證書中心列出所選船舶的證書**聲明**及其聲明的日曆狀態。它回答的問題是：「這艘船上哪些證書臨近到期或檢驗窗口？哪些紀錄仍在等待人工審查？」顯示的日期是聲明。本頁絕不會判定證書有效或已查證（13.03 §1, §8）。

## 誰使用本頁
- **船長、輪機長 / 技術主管：**關注船舶的證書日曆，輸入新的證書草稿並開始續期準備。
- **法規 / 保證使用者：**檢查聲明是否依據官方的、有版本的來源，並記錄被指派稽核員的聲明（13.03 §8）。
- 只有讀取權限的使用者只能看到清單，不能進行變更。

## 開始之前
- 檢視需要證書讀取權限。輸入草稿需要證書寫入權限以及該船舶的編輯範圍；擷取文件建議需要檔案讀取和擷取權限；記錄人工聲明需要目錄寫入權限、查證紀錄權限，以及針對此船舶和證書的目前**稽核員**任命。受保護的船員聲明還需要船員讀取、船員證書讀取、船員身分讀取和檔案讀取權限。
- 先選擇正確的船舶：在**選擇船舶**清單中按該船舶（13.03 §1）。
- 本頁需要即時線上讀取。離線時您會看到「目前證書來源在離線時不可用或被隱藏。」，且不會推斷任何離線授權。

## 操作步驟
1. 從**選擇船舶**清單中開啟船舶。
2. 使用**證書範圍**選擇**船舶證書**，或（如果您擁有權限）選擇**受保護的船員聲明**。使用**聲明的日曆篩選**縮小清單範圍。
3. 按某一列以開啟紀錄。各列帶有**未查證的證書聲明**標籤。
4. 對於新紀錄，按**新增證書草稿**。根據來源文件填寫**文件名稱**、**聲明的法規依據**、**聲明船旗**、檢驗窗口和**聲明的可用情況**，然後按**儲存未查證草稿**。
5. 要從連結文件中取得建議，請在**審查文件事實**中按**從連結文件擷取**。將每條建議與來源進行比較，勾選**我已對照來源檢查此事實**和**我已檢查此文件屬於此船舶及證書**，然後按**確認選取事實並儲存草稿**。
6. 作為被指派的稽核員，在**人工聲明記錄**中填寫**選擇實際任職**和**選擇記錄的主張**並輸入理由，然後按**記錄未經評估的聲明**。
7. 要開始續期，請在紀錄的**證書相關工作**下使用**準備續期**。這會帶您進入[證書續期](/app/renewal-workflow)流程。

## 狀態含義
- **聲明到期 <90 天 / <60 天 / <30 天 / 聲明的到期日已過：**根據聲明的到期日期得出的日曆觀察。它不是對有效性的決定。
- **聲明的檢驗窗口已開放 / 超出到期窗口：**相對於聲明的檢驗窗口的位置。
- **需要日曆審查：**某個日期缺漏、含糊或相互衝突。在有人對照來源文件檢查之前，該紀錄尚未就緒。
- **未知：**該值未被聲明。未知的值絕不表示「未缺漏」或「合規」；它需要審查。
- **低信賴度 · 審查 / 含糊 · 審查 / 需要審查：**尚未經人確認的文件建議。信賴度分數不是查證。
- 「僅限此頁。日曆觀察與資格認定是分開的；這些不是全船隊的就緒總數。」

## 不能做的事 / 注意
- 儲存草稿並不會查證證書。撰寫紀錄、確認文件建議和稽核員的聲明是彼此獨立的步驟；已完成 ≠ 已查證。
- 自動擷取只提供建議。缺漏的值保持未知，只有您選擇並更正的事實才會更新草稿。
- 僅憑管理員角色不能記錄人工聲明；需要目前的任命和來源檔案。
- 已儲存的證書絕不會被靜默變更。每次儲存都會建立一個新的修訂版本，較早的修訂版本保留在**已記錄修訂版歷史**中（13.03 §1）。
- 本頁不授予任何船級、船旗或主管機關的核准，也不決定航次適航性。該決定屬於獲授權人員。

## 發生問題時
- **證書來源或存取不可用。不得推斷清單有效、為空或已查證。**按**重試來源讀取**。如果問題持續，請檢查您的角色、船舶和物件範圍；必要時聯絡租戶管理員（13.03 §10）。
- **結果未知。**保留原始指令，並使用**重試原證書命令**重新傳送同一請求。
- **目前來源已變更。**您的本機欄位會被保留；使用**返回記錄**，重新讀取目前紀錄並重新進行變更。
- **此文件無法自動讀取：**請根據來源文件手動輸入值。
- 如果紀錄無法查證，請檢查其證據和來源沿襲，並轉交給查證人（13.03 §10）。
