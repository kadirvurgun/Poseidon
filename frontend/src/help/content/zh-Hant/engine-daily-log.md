## 本頁用途
輪機日誌將所選船舶的**輪機值班紀錄**連同其記錄的來源版本作為草稿保存。它回答的問題是：「輪機值班就主機狀態和運轉時數、燃油和潤滑油消耗、淡水、關鍵測量、報警、缺陷、加油、艙底水和環保控制聲明了什麼？輪機長是否已針對此確切修訂版記錄了審查？」儲存的條目是未經查證的聲明。草稿資料不會被轉化為排放、燃油保證或就緒結論。

## 誰使用本頁
- **值班輪機員（Crew / OOW / 輪機員）：**即時並按時間順序保持輪機值班紀錄（13.03 §6）。
- **輪機長：**審查已儲存的日誌，將其連結到工單和缺陷，並將審查作為人工行為記錄（13.03 §5）。只有擔任輪機長職務的任命才能記錄輪機日誌審查。

## 開始之前
- 在頂部情境列中選擇**正確的公司和船舶**。
- 讀取需要 `daily.engine.read`；儲存需要 `daily.engine.write` 以及對此船舶的編輯權限。記錄審查需要 `daily.engine.write`（附對此船舶的編輯權限）、`daily.engine.review`，以及針對此確切紀錄的目前輪機長任命。
- 連結工單或缺陷還需要這些紀錄的讀取權限。

## 操作步驟
1. 選擇船舶。**已記錄草稿**按日期和修訂版本列出每份日誌，並顯示「草稿 · 需要審查」。
2. 按**新增草稿**，或開啟列出的日誌進行**編輯已記錄草稿**。
3. 填寫**輪機值班情境**、**輪機狀態與時數**、**消耗與生產**、**測量、報警與缺陷**以及**工作與環境情境**。為每個欄位選擇**已知**、**未知**或**缺漏**。
4. 按**儲存草稿**。每次儲存都會在**已記錄修訂版歷史**中新增一個修訂版本。
5. 在已儲存的日誌上，使用**工單與缺陷**：選擇**紀錄類型**和**記錄**，然後選擇**連結**。一個連結固定一個確切的修訂版本；**移除連結**會將其移除。
6. 必要時，開啟**從已儲存來源開啟燃油記錄**或**從已儲存來源開啟停機記錄**。數量和單位不會被複製。
7. 輪機長開啟**人工審查記錄**，選擇**經授權人員任命**和**審查條目**，寫下**審查理由**，然後按**記錄審查條目**。

## 狀態含義
- **未經查證的聲明 / 已知 / 未知 / 缺漏：**聲明的值及其資料狀態。未知不等於「否」、「就緒」或「不適用」。
- **待處理 · 未記錄審查：**此修訂版本不存在人工審查。
- **已記錄人工中繼資料 · 未經評估：**此修訂版本存在一筆輪機長審查條目。它不構成查證或輪機長簽署。
- **目前修訂版本 / 存在較新的修訂版本：**連結的工單或缺陷自連結以來是否已變更。連結僅表示沿襲關係；它不查證、不關閉也不核准該紀錄。
- **查詢無法使用 — 未知：**以您的存取權限無法讀取該連結紀錄類型。

## 不能做的事 / 注意
- 系統絕不會審查日誌或使其定稿。審查是由被任命的輪機長進行的人工行為（13.03 §5）。
- 撰寫過日誌任一修訂版本的人不能審查它。不會向作者提供任命，頁面會顯示「您撰寫了此日誌修訂版本；必須由獨立的審查人記錄審查。」；伺服器也會基於職責分離拒絕此類審查。
- 保持條目即時並按時間順序記錄；不要變更他人已審查的紀錄（13.03 §6）。
- 在此處連結缺陷不會記錄限制，也不會關閉缺陷；這些操作請在缺陷或工單頁面上進行（13.03 §5）。
- 連結需要目前的線上連線；離線時不會連結任何內容。離線衝突絕不會被自動合併。

## 發生問題時
- **「日誌條目已變更。請在變更連結之前重新載入。」：**重新載入，然後再次連結。
- **「儲存結果未知」：**使用**重試原已儲存命令**；不要重新輸入。
- **「需要人工解決衝突」：**開啟**審查衝突**或衝突中心並明確作出選擇（13.03 §10）。
- **沒有可用的任命或存取遭拒：**與您的租戶管理員一起檢查您的角色和船舶情境（13.03 §10）。
