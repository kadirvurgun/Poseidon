## 本頁用途
塢修計畫保存所選船舶的**塢修工程包**（專案、造船廠、計畫日期和範圍項目）。它回答的問題是：「每個塢修範圍項目連結到哪個工單、缺陷、證書或檢驗檢查清單？這些連結是否為目前版本？」範圍與這些紀錄相連結（13.03 §5）。**關聯就緒度**僅表示連結的完整性；它不是船級或船旗檢驗結果，也不是適航聲明。

## 誰使用本頁
- **技術主管：**準備塢修工程包，將範圍連結到紀錄，進行計畫並完成（13.03 §5）。
- **輪機長：**追蹤範圍與缺陷和工單紀錄的連結情況，並在有權限時查證他人完成的工程包（13.03 §5）。

## 開始之前
- 選擇正確的船舶。如果未選擇船舶，本頁會顯示**請從工作區選擇一艘船舶以繼續。**
- 您需要塢修讀取權限才能查看工程包。建立、編輯和變更狀態需要寫入權限；查證需要查證權限。
- 準備好您要連結的工單、缺陷、證書和檢驗檢查清單紀錄的識別碼和修訂版本。

## 操作步驟
1. 從清單中開啟一個工程包，或使用**建立塢修工程包**建立一個空草稿。
2. 填寫**塢修專案**、**造船廠**、**計畫開始**和**計畫完成**。
3. 使用**新增範圍項目**新增項目；輸入**範圍項目**類型、**標題**、**工作包**、**船級要求**、**法定要求**和**優先級**。
4. 在每個項目上，使用**新增關聯**並輸入**紀錄類型**、**紀錄識別碼**和**固定修訂版本**。
5. 為完成工作，在**完成證據**下使用**新增**新增證據參照。然後按**儲存**。
6. 檢查**計畫阻礙項目**或**完成阻礙項目**清單。在**變更狀態**下，選擇一個**操作**（**計畫**、**退回草稿**、**開始塢修**、**完成塢修**、**取消工程包**）並確認。取消需要備註。只提供對目前狀態有效的操作；工程包只有在草稿或已計畫狀態時才能取消。
7. 對於不是由您完成的已完成工程包，寫下至少 10 個字元的**理由**，然後使用**核驗紀錄**或**駁回核驗**。
8. 在**時間軸**中追蹤計畫日期、實際日期和每個修訂版本。

## 狀態含義
- **草稿 / 已計畫 / 進行中 / 已完成 / 已查證 / 已取消：**工程包的生命週期。已完成和已查證不是一回事。
- **連結為目前版本 / 關注 / 需要審查 / 不完整：**關聯就緒度。即使連結為目前版本，這也不是檢驗結果。
- **已連結 / 未連結 / 已逾期 / 需要審查：**範圍項目的連結狀態（當任一連結為過時或不可用時為需要審查）。
- **目前 / 過時 / 不可用：**連結紀錄與其固定修訂版本的比較。請審核過時的連結，並使用**重新固定至**將其固定到新的修訂版本。
- **未知 / 未設定：**未輸入優先級。未知不等於「普通」或「低」。

## 不能做的事 / 注意
- 本頁不判定塢修是安全的，也不判定船舶適航。
- 您不能查證自己完成的工程包。駁回核驗會使工程包回到**進行中**。
- 成本、幣別、供應商和預算只是外部參照；此處不進行加總、核准或訂購。
- 已完成、已查證或已取消的工程包不能編輯。
- 離線時不會傳送指令。

## 發生問題時
- **伺服器列出了缺漏或阻礙的項目：**解決阻礙項目清單後再試一次。
- **紀錄已變更或指令衝突：**使用**重新載入最新版本**並審核。
- **結果未知：****重試**會再次傳送完全相同的指令。
- **您無權存取此紀錄：**檢查您的角色和船舶情境；必要時聯絡您的租戶管理員（13.03 §10）。
- **您無法讀取以下關聯紀錄類型：**與紀錄負責人或您的租戶管理員確認權限。
