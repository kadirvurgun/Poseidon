## 本頁用途
「要求草稿」頁面將從來源修訂版衍生的**要求**作為有版本的草稿保存，並將每項要求綁定到確切的來源修訂版。它回答的問題是：「這項要求依據的是哪個來源的哪個修訂版？它記錄的生命週期是什麼？」要求是要求 → 控制 → 證據 → 查證鏈中的第一個環節。該鏈中的任何紀錄都不應處於未連結（孤立）狀態（13.03 §8）。

## 誰使用本頁
- **法規 / 保證使用者：**將要求綁定到其來源，使用情境輸入評估適用性，並保持鏈條完整（13.03 §8）。
- **DPA / HSEQ：**在發現事項和稽核工作中閱讀要求的依據（13.03 §4）。

## 開始之前
- 檢視需要租戶範圍讀取和法規草稿讀取權限；編輯還需要法規草稿寫入權限。
- 子檢視需要各自的權限，且始終需要租戶範圍的讀取範圍。**生命週期與適用性**需要適用性讀取權限；編輯規則需要規則寫入權限，請求審核需要規則審核權限，評估需要適用性評估權限；資格認定和事實證明需要法規資格認定或事實證明權限，以及伺服器中已記錄的任命。**控制與證據**需要控制讀取、證據讀取、檔案讀取和適用性讀取權限；連結需要控制寫入或證據寫入權限以及對船舶的編輯權限，核准需要控制核准權限。
- 請先在**來源草稿**頁面上記錄來源。要求只能綁定到已存在的來源修訂版。
- 儲存需要即時的伺服器連線；離線時，編輯會保留在分頁中。

## 操作步驟
1. 在清單中查看要求草稿；使用「搜尋草稿」和**搜尋**進行搜尋。
2. 對於新要求，按**新增草稿**。
3. 在「草稿欄位」中，為每個欄位選擇**狀態**（**缺漏**、**未知**、「已知（已聲明）」），並輸入已知的值：**法規文書**、**版本 / 修正案聲明**、**聲明的生效日期**、**聲明 / 溯源資訊**、**來源觀測時間（含 UTC 時差）**。
4. 在「不可變更來源引用」中，在「尋找來源」中輸入內容並按「搜尋來源」。在「來源草稿」中選擇來源，然後在「確切修訂版」中選擇確切的修訂版。使用「所選不可變更來源內容」檢查所選修訂版的內容。
5. 按**儲存草稿**。紀錄開啟後，會顯示**記錄的生命週期**和**不可變更歷史**區段。
6. 使用**生命週期與適用性**處理適用性，使用**控制與證據**處理控制和證據連結。**控制與證據**中的**關鍵孤立項報告**列出沒有連結要求的關鍵聲明；請將這些紀錄連結到某項要求。

## 狀態含義
- **記錄的生命週期：**伺服器根據綁定的規則得出的狀態：**草稿**、**已採用**、**未來生效**、**已生效**、**已被取代**。如果無法讀取，則顯示**無法使用**；系統不會假定為草稿或已生效。
- 「綁定的規則記錄了不同的生命週期狀態。所示值是軟體的優先順序；需要專家審核。」此時所示值不是決定；需要專家審核。
- **未知：**該資訊未知。當關鍵資料未知時，適用性結果保持**需要審查**（REVIEW_REQUIRED）；它絕不會被計為「不適用」或「否」（13.03 §8）。
- **需要適用性審核 / 缺少要求連結 / 未執行查證：**控制-證據鏈中的未決事項。
- **完成未知 · 未查證 · 有效性未知：**完成、查證和有效性是彼此獨立的狀態。已完成的紀錄並不等於已查證，已查證的紀錄也不等於有效。

## 不能做的事 / 注意
- 您不能將要求綁定到「最新」的來源；始終需要選擇**確切修訂版**。當來源有新的修訂版時，舊的綁定會保留在歷史中。
- 適用性預覽不構成任何合規、就緒、許可或法律核准：「預覽 / 草稿。預測不構成合規、就緒、許可或法律核准。」
- 生命週期變更需透過**請求人工審查**進行；由來源准入和合格的獨立審核人作出決定。系統絕不會自行關閉它。
- 不要假定船級協會、船旗國、公司和地方規則來源可以相互替代（13.03 §8）。

## 發生問題時
- **來源選擇不可用。**按「重試來源」。
- **衝突。您的編輯已保留。請先捨棄編輯再重新載入。**使用**重新載入已儲存草稿**開啟目前修訂版。
- **請檢查欄位狀態、範圍、日期和來源修訂版。**如果您選擇了來源，也請選擇其確切的修訂版。
- **歷史不可用。編輯器內容已保留。**按「重試歷史」。
- 如果生命週期出乎意料，請審核綁定的規則和來源修訂版；必要時聯絡控制負責人或領域專家（SME）（13.03 §10）。
- 如果沒有權限，請檢查您的角色和租戶範圍，並詢問租戶管理員（13.03 §10）。
