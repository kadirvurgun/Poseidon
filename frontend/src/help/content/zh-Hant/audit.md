## 本頁用途
「操作歷史」頁面以**唯讀**方式顯示您獲授權範圍內業務紀錄變更的署名紀錄。它回答的問題是：「這筆紀錄何時發生了變更？是什麼操作？在哪個操作者和角色情境下進行？」安全事件另行受限，不會出現在這裡（13.03 §4, §9）。

## 誰使用本頁
- **DPA / HSEQ：**追溯發現事項、措施和查證紀錄（13.03 §4）。
- **法規 / 保證使用者：**在稽核或審查前檢查紀錄歷史（13.03 §8）。
- **租戶管理員：**稽核成員資格和權限變更，以及委派的開始和結束時間（13.03 §9）。

## 開始之前
- 檢視需要稽核讀取權限。沒有該權限時您會看到「需要稽核權限。」
- 只列出您獲授權的租戶和船舶範圍內的紀錄。
- 如果您在尋找特定紀錄，請準備好其**船舶 ID**或**物件 ID**。其他頁面上的歷史連結會以已篩選的狀態開啟本頁。

## 操作步驟
1. 填寫篩選條件：**船舶 ID**、**物件 ID**、**物件類型**和**操作**（**全部**、**已建立**、**已更新**、**已刪除**）。
2. 按**篩選**。使用**清除篩選**重設。
3. 查看**已授權記錄**中的**時間**、**物件**和**操作**欄。使用**首頁**和**下一頁**在頁面之間切換。
4. 按某一列的物件連結開啟**記錄詳細資訊**。閱讀**操作者參考編號**、**已分配角色參考編號**、**受信任能力**、**理由**、**中繼資料**、**資源版本**和**關聯**。
5. 如果存在不可變更修訂版證據，按**開啟確切的不可變更修訂版**查看紀錄當時的樣子。按**關閉**關閉詳細資訊。

## 狀態含義
- **已建立 / 已更新 / 已刪除：**對紀錄執行的操作類型。
- **已記錄：**中繼資料已完整擷取。
- **歷史中繼資料不完整 / 歷史識別碼不可用 / 歷史情境不可用：**較早的紀錄沒有保存這些資訊。缺漏的資訊絕不會透過猜測來填補。
- **不予披露的值：**基於隱私原因隱藏欄位值；只顯示它已發生變更這一事實。
- **此記錄無可用的不可變更修訂版證據。**此紀錄類型沒有修訂版快照。

## 不能做的事 / 注意
- 本頁為唯讀。操作歷史項目不能被編輯或刪除。
- 紀錄出現在歷史中並不表示工作已查證或已生效；已查證 ≠ 已生效（13.03 §4）。
- 本頁記錄業務變更。僅憑本頁並不構成完整的使用者操作稽核，也不能證明符合隱私合規要求；安全事件另行保存。
- 清單只顯示您獲授權的範圍。範圍外的紀錄不會列出；看不到某筆紀錄並不表示它從未被變更。

## 發生問題時
- **需要稽核權限。**檢查您的角色和範圍；必要時聯絡租戶管理員（13.03 §10）。
- **請登入以繼續。**重新登入。
- **歷史不可用。請檢查篩選條件後重試。**檢查識別碼是否完整、正確，然後按**重試**。
- **沒有符合這些篩選條件的已授權記錄。**放寬篩選條件。
- 如果應用程式錯誤持續存在，請附上關聯 ID、畫面、時間和操作步驟向支援團隊回報（13.03 §10）。
