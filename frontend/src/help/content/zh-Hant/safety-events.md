## 本頁用途
「安全事件與虛驚事件」頁面讓您快速通報船舶上的安全事件，並追蹤其後的人工步驟：分類、調查、獨立審查、矯正與預防措施、查證、有效性和結案。它回答的問題是：「發生了什麼？由誰處理？措施是否真正有效？」這裡不會自動決定嚴重程度、根本原因或結案；每一項都是另外的人工紀錄。本頁遵循發現事項 → 措施 → 查證鏈，且**已結案不等於有效**（13.03 §4）。

## 誰使用本頁
- **Crew / OOW / 輪機員和船長：**通報虛驚事件、事故、意外、疲勞、環境或網路事件（13.03 §2, §6）。
- **DPA / HSEQ：**作為安全橋樑，關注關鍵事件和逾期措施，並管理調查和措施有效性（13.03 §4）。
- 分類、調查、審查、身分讀取、措施撰寫、查證和有效性審查是彼此獨立的權限；每個使用者只能看到自己擁有權限的部分。

## 開始之前
- 選擇正確的船舶（**選擇船舶**）。沒有存取權限時，您會看到「您無權存取此船舶的安全事件。」
- 通報需要通報權限；讀取清單需要讀取權限。
- **保密**通報和**提交通報**需要網路連線。離線時您只能儲存實名草稿，且只能在事先準備好的裝置上進行。
- 時間以 UTC 輸入。

## 操作步驟
1. 在**事件**清單中查看該船舶的事件。使用**僅我的通報**只查看您自己的通報。
2. 對於新紀錄，按**通報事件**。在**通報方式**中選擇**實名**或**保密**。對於需要追蹤的保密通報，請選擇**給我一組私人追蹤碼**。
3. 填寫**事件類型**、**何時發生？**、**作業**、**船上位置**、**摘要**、**發生了什麼**、**是否採取了立即措施？**，並可選擇填寫**您估計的嚴重程度**。如果時間不明，請選擇**未知**並填寫**為什麼時間不明？**。
4. 內容不完整時可以**儲存草稿**。當**送出前仍需填寫**為空時，按**提交通報**。未提交的草稿可以透過**撤回草稿**並附理由撤回。
5. 如果簽發了追蹤碼，請立即私下保存**您的保密追蹤碼**中的代碼，然後按**我已保存**。它只顯示一次。之後，在**保密追蹤**下將其輸入為**追蹤碼**，並按**開啟**閱讀團隊回覆。
6. 分類人員在**初步分級**中附理由記錄嚴重程度和**需要調查**，然後按**記錄分類評估**，或使用**退回給通報人**退回。
7. 調查人員按**開啟調查**，填寫**促成因素**、**根本原因**、**屏障**和**不確定性**，然後按**儲存調查**和**提交審核**。在**獨立審查**中，由另一人選擇**核准**、**退回**或**拒絕**。
8. 在**矯正與預防措施**中，使用**新增措施**並填寫負責人、到期日期以及所針對的發現事項。由負責人記錄**回報完成**，另一人記錄**驗證**，第三人記錄**審查有效性**。
9. 當**結案阻礙項目**為空時，由既不是通報人也不是調查撰寫人的審查人（具有審查權限）按**結案此事件**。在**訊息**中，您可以以**僅限團隊**或**與通報人共享**的可見範圍傳送訊息。

## 狀態含義
- **草稿 / 已提交 / 已退回 / 已分類 / 調查中 / 措施追蹤 / 已結案 / 已撤回：**事件的生命週期。
- **嚴重程度 — 未分類 / 未評估：**尚無人工分類。**通報人估計**僅為建議。**嚴重程度政策：未設定 – 僅人工分類**表示系統不會推導嚴重程度。
- **調查需求為 UNKNOWN：**尚未作出決定；它不表示「否」，並且會阻止結案。
- **措施 — 未結 / 已完成 / 已查證：**已完成不等於已查證，已查證也不等於有效。
- **有效性 — 待處理 / 有效 / 無效 / 無定論 / 無措施 / 不可見：**有效性是針對每項措施的人工審查，與結案是分開的。**無措施**並不表示有效。
- **未結案的安全事件**摘要：**存在未結案的高嚴重程度事件**、**需要審查**或**無未結案的高嚴重程度事件**。它只是警告；它不提供任何就緒決定。
- **保密（受保護）：**通報人身分保存在受限保管庫中，不會向讀者顯示。
- **離線擷取 / 等待同步 / 已儲存到此裝置。尚未傳送。**排入佇列不等於已傳送。

## 不能做的事 / 注意
- 通報人不能對自己的通報進行分類。調查撰寫人、提交人或通報人不能進行獨立審查。
- 只有措施負責人才能回報完成。負責人和完成人都不能查證；負責人、完成人和查證人都不能審查有效性。這些是由不同人員作出的獨立紀錄。
- 根本原因是人工陳述；系統絕不會提出根本原因。
- 已提交的通報絕不能由其作者撤回或刪除。
- 在保密通報中，身分只按需知原則開啟，由擁有身分讀取權限並選擇**目的**的人開啟；每次讀取都會連同其目的被記錄。匿名通報需要公共受理管道，而該管道尚未設定。
- 無定論的審查可以重複進行；有效和無效是最終結果；無效的措施需要新的後續措施。

## 發生問題時
- **伺服器拒絕了指令：**補全其下方列出的缺漏或阻礙項目。
- **該紀錄在此期間已變更。請重新載入並檢視後再試。**按**重新載入**。
- **結果未知（連線中斷）。**使用**重試同一命令**；它不會被執行兩次。
- **您無權執行此操作。**檢查您的角色、船舶和物件情境；必要時聯絡租戶管理員（13.03 §10）。
- **裝置金鑰不可用**或**需要線上重新授權：**已擷取的資料會被保留；連線時請重新授權。如遇應用程式錯誤，請附上關聯 ID、畫面、時間和操作步驟聯絡支援團隊（13.03 §10）。
