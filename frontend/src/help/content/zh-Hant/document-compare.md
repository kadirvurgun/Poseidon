## 本頁用途
本頁針對所選船舶，**以唯讀方式並排顯示受控文件的兩個修訂版**。它回答的問題是：「這兩個修訂版在檔案和中繼資料層面有什麼不同？各自的發布、查證和保管歷史是什麼？」本頁顯示差異；它不核准、不發布，也不評判變更。它不會使某個修訂版生效，也不會使其取代較早的修訂版。證據原件絕不會被靜默變更；當新修訂版取代較早的修訂版時，較早修訂版的發布狀態變為「已取代」，該事件會出現在其保管歷史中（13.03 §1）。

## 誰使用本頁
- **船長 / 輪機長 / 船員：**將生效的修訂版與上一個修訂版進行比較，並記錄閱讀確認（13.03 §2, §5, §6）。
- **DPA / 法規與保證使用者：**審核修訂歷史和查證紀錄（13.03 §4, §8）。

## 開始之前
- 如果未選擇船舶，本頁會顯示**請選擇您權限範圍內的船舶。**並列出船舶。請選擇正確的船舶。
- 您需要檔案讀取權限才能查看本頁。受限內容和 ISPS 受限文件還需要各自的權限。
- 載入內容和記錄確認只能在線上進行。

## 操作步驟
1. 從**受控文件**清單中開啟一份文件。分類和**ISPS 受限**標籤顯示在該列上。
2. 在**選擇兩個修訂版**下，選擇**左側（基準）**和**右側（審閱）**修訂版。本頁首先在右側建議最新修訂版，在左側建議其前一個修訂版。
3. 按**比較**。使用**交換左右**進行互換。
4. 閱讀位元組說明和**中繼資料比較**表：**檔案類型**、**大小（位元組）**、**內容 SHA-256**、**接收**、**發布**、**查證**以及時間欄位。
5. 審核每一側的**核准與保管歷史**。
6. 要查看內容，請按**載入內容（存取將被記錄）**。內容會帶有署名浮水印顯示。
7. 在**載入內容**之後，如果您已閱讀生效的修訂版，請勾選**我已閱讀此修訂版並能存取其內容。**並按**記錄閱讀確認**。

## 狀態含義
- **未發布 / 已生效 / 已取代：**修訂版的發布狀態。未生效的修訂版顯示**未在營運中生效**。
- **未查證 / 查證為有效 / 查證為無效 / 查證無定論：**修訂版的查證紀錄。未查證並不表示「有效」。
- **相同 / 已變更 / 不可比較：**中繼資料列的結果。不可比較並不表示「相同」。
- **位元組完全相同的檔案：**僅表示位元組相同；這不是內容審核。
- **檔案在位元組層面存在差異：**哪條規則發生了變化及其重要性，需要由人審核。
- **您的角色無權檢視內容；僅顯示中繼資料。**此角色無法開啟內容。

## 不能做的事 / 注意
- 您不能在本頁發布、核准、使文件生效或取代文件。
- 本頁不會自動解釋內容差異；由獲授權人員判斷其重要性。
- 確認只針對生效的修訂版記錄，每人每個修訂版一次。它不是核准，也不是查證。
- 列印的副本不受控。內容不會被快取，也不會離線保存。
- 離線時比較結果已過時，且無法載入新內容。

## 發生問題時
- **您無法使用此文件：**檢查您的船舶情境和權限；必要時聯絡您的租戶管理員（13.03 §10）。
- **您沒有執行此操作的權限：**檢查您的角色和船舶情境（13.03 §10）。
- **紀錄在此期間已變更：**使用**重新載入**開啟最新版本。
- **某個修訂版無法查證：**檢查證據和溯源歷史；與獲授權的查證人溝通（13.03 §10）。
- **請求失敗：**將畫面、時間和操作步驟傳送給支援團隊（13.03 §10）。
