Gizli üyeler nedeniyle eksiklik işareti üretilmez. Bu kural yeni state veya izin eklemez.

## paragraph:911

TaskRow.rowId yalnız görüntüleme/sıralama kimliğidir; SourceRef veya yetki kanıtı değildir. Yeni tanımda RFC 4122 UUIDv5 kullanılır. Sabit namespace N = UUIDv5(namespaceURL=6ba7b811-9dad-11d1-80b4-00c04fd430c8, UTF8("urn:poseidon:mobile:task-row:v1")) değeridir. Satır adı UTF8(RFC8785 JCS({tenantId:<küçük harfli kanonik UUID>,owner:<RegisteredOwner literal>,kind:<kaynak Code aynen>,id:<küçük harfli kanonik kaynak kök UUID>})); rowId=UUIDv5(N,satır adı). UUIDv5 standart SHA-1 ve version/variant bit yerleşimini kullanır; bu kimlik üretimi güvenlik hashı veya imza doğrulaması değildir. revisionId, principal, durum, başlık, sayfa ve zaman önimgede yoktur. Aynı kökün revizyonları aynı rowId; farklı tenant/owner/kind/id farklı ad girdisidir. Kaynak kind büyük/küçük harfi dönüştürülmez; kaynağın kanonik Code değeri kullanılır. Aynı sonuç UUID farklı tam kimlik dörtlüsüne denk gelirse satırlar birleştirilmez; 503 ROW_IDENTITY_COLLISION ile güvenli ret verilir. Eski saklanan kaynak UUID, kaynak hashı veya receipt kimliği yeniden yazılmaz; mevcut sort dueAt ASC null last,rowId ASC değişmez.
