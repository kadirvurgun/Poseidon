Lead decisions applied:

1. Deviations now come from a static source review of every endpoint plus the probe. `EndpointProfileSourceReviewTests` finds empty-body error results (`Results`/`TypedResults` `NotFound()`, `BadRequest()`, `Unauthorized()`, `Conflict()`, `UnprocessableEntity()`, `StatusCode(..)`, `Forbid(..)`) in `backend/Poseidon.Api/**/*.cs`. It attributes each line to its compiled method through portable PDB sequence points and links methods to endpoints through an IL call graph walked from each host handler `MethodInfo`. It also checks framework parameter binding. Deviations must match exactly, and an occurrence that no handler reaches fails the test.
