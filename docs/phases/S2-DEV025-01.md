  restores only what it changed; Tab trap uses shared `focusableTargets` (tabindex ≥ 0), so
  the preview samples are never in the cycle (PR #18 QA notes closed). Native `<dialog>`
  modals (vessel chooser, search, draft confirm) verified for focus return.
- Narrow-screen context summary (65.03 paragraph 48, handed over by DEV-021): ≤767 px, one
  button named with workspace, company, vessel, mode, role and connection; `aria-expanded` /
  `aria-controls` disclose the details; the polite live summary is only visually clipped; no
  summary while the context is unverified.
- Sticky top bar: measured `--shell-sticky-offset` drives `html { scroll-padding-top }`; the bar
  is not sticky at `max-height: 31.25rem` (200 %/400 % zoom), so focus is never under it.
- Contrast/tokens: context bar colours from tokens (fixed `#3f717c` connection label failed in
  dark mode); shell pairs verified for 3 built-in palettes and 50 builder combinations.
- RTL: appearance popover uses logical insets and spans the top bar on ≤580 px, inside the
  320 px viewport in en and ar; drawer anchors to the inline-start edge.
- Reduced motion applies globally (portals included).
- Forms: shared `FormErrorSummary` (focus on submit, links to fields, not a live region),
  adopted in the directory editor; `errorSummary` copy in all 17 catalogs.
