- **DEV-031 test defect, not a product defect.** The test changed `ActorKind` to a non-human value and only then built the rejection command with `CurrentReviewCommand(...,"human.decide")`. That helper reads `/api/v1/regulatory-trace` (`HumanReviewTests.cs:50`). The trace is itself human-only (`HumanReviewEndpoints.cs:51,82`: `ActorKind != "Human"` gives no reader and no authorities, so 403 `trace_reader_required`), so `GetFromJsonAsync` threw before the decision gate was ever exercised. Fix (`HumanDecisionAuthorityTests.cs:39-52`): build the exact rejection envelope while the principal is still the appointed human, then switch. The test now also asserts the trace is 403 for the non-human principal. It is tightened, not relaxed: the REJECTED path must now be exactly 403 `human_authority_required` (it was `Forbidden or BadRequest`). Code reading confirms this is deterministic: `Grant()` returns null for a non-human principal → `HumanReviewEndpoints.cs:357`. The rule is unchanged: no non-human principal can create, finalize or reject a decision.
- **ShipOps post-commit revocation (outside S3, pre-existing).** Hypothesis: the harness raced the request against the wall clock. `WaitForComplianceAuditLock` gave the pending request a fixed 3 s to reach the paused `ShipOperationsCommand/Success` audit insert. On a fresh host, that span covers the antiforgery token request, a cold SERIALIZABLE write, several fence queries with dynamically built expression trees (first EF compilation in the shard) and two audit connections. On a loaded 4-shard runner this can exceed 3 s. The product path itself has no competing writer (each test owns its database), so there is no SSI or `40001` source. Branch `integration/bundle5-20261119` e5628df (`Superseded()` re-read) concerns a competing edit before the pre-transaction fence and does not interact; it is not duplicated. Fix (`ComplianceResponseFenceTests.cs:98`): the wait is now bound to the request's own progress. If the pending request completes without ever blocking, the test fails at once with its status. The outer bound is 30 s, matching the pending-response bound. No assertion is relaxed. Not reproduced locally (no Docker); confirmation needs CI.
