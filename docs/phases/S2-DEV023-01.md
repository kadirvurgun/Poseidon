## Delivered behavior

- `GET /api/v1/poseidon-today`: every card has `sourceRef {owner: REGULATORY|PMS|TUG, kind, id, revision, savedAt}` taken from the same current read as Why (absent draft: `null` revision/time). Response has `viewState` (`TodayViewStatePolicy`: Unavailable/Partial/Empty/Ready); with the operational/safety/permit/evidence owners not connected it is always Partial or Unavailable, never a green state.
- Next action follows the owning module write gate: `ReviewMaintenancePlan`/`ReviewTugJob` only with `maintenance.write` / `tug.plan.write` + vessel edit, else `ViewMaintenancePlan`/`ViewTugJob`; Why reuses the card action. `TechnicalEndpoints.Write` and `TugEndpoints.PlanWrite` became `internal` (visibility only). Today still writes nothing.
- UI (`TodayWorkspace`): per-card source block (owner module, record, revision, save time), view-state notice (text + icon), "partial sources: zero is not all clear" note on the counters, fixed error mapping (401/403/404/429/502/other), `aria-busy` + `data-today-state` (loading/ok/error/offline). 15 new strings in all 17 locale catalogs (`TodayWorkspace_tsx_copy`).
- Client decoder: requires `sourceRef`, checks its owner/kind/id against the card key, requires a positive revision and save time (except absent draft), allows only Review/View actions, and recomputes `viewState` from coverage, so a promoted state is rejected (502).
- OpenAPI re-exported from the actual Release host (`scripts/export_openapi.py`) and `npm run generate:api` regenerated. The export also reordered schemas `OnboardingBlocker`/`WorkspaceCompanyDto` (inherited, order only).
