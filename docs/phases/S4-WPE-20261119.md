## Existing implementation reused (not rewritten)

Per-resource conflict detail/resolution already existed on main: crew `OfflineApplicationEndpoints`
(`/conflicts/{command}`, reasoned `ParentCommandId` + `ExpectedServerVersion` replay, audited
`OfflineConflictRead`), tug and daily equivalents, and `OfflineConflictReview.tsx` (before/local/server,
no preselected choice, required reason). WP-D owns queue/sync internals; this package only consumes
`OfflineApplication.authorize/conflict/captures/capture/replay/discard`.

## Delivered

- `GET /api/v1/sync/conflicts?vesselId=&offset=` (`backend/Poseidon.Api/SyncConflictCenterEndpoints.cs`):
  read-only index of the current actor's own `MaterialConflict` outcomes across crew/tug/daily sources for a
  scoped vessel; per-source current read rights (`Included/Partial/NotPermitted`), closed query (forged
  members rejected), bounded paging, Open/Superseded/Resolved state from successor lineage, no field values,
  `SyncConflictList` security audit for Success/Invalid/NotFound/Denied. Profile `NATIVE-READ-1` added to
  `contracts/endpoint-profiles.v1.json`; OpenAPI and `api.d.ts` regenerated. Not a write, so no S1 critical
  scope/AuditMetadata change.
- `/app/offline-conflict-center` screen (`frontend/src/product/ConflictCenterWorkspace.tsx`): vessel
  selection, loading/empty/error-retry/denied/offline/hidden states, field-level before/local/server diff via
  the shared review, explicit choices keep server / reapply mine (new command with the fresh expected
  version) / discard local copy (explicit confirmation), unknown outcome → check-outcome only, no success text
  before an exact decoded server receipt, keyboard (Enter/Escape, focus to review), 17-locale copy
  `ConflictCenter_tsx_copy`.
- `conflict-center-resolver.ts`: retained unconfirmed resolution is reused (never duplicated or re-decided);
  `409 offline_conflict_changed` withdraws the no-effect frozen decision and requires a fresh review.
- Tug/daily rows are listed but resolved only in their owning panels (stated in the UI).
