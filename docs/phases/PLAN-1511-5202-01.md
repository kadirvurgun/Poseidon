## Delivered behavior

- Persisted federated `identity.Accounts` (issuer+subject unique across tenants, actor id as
  account id, no password/hash/token/e-mail), `identity.Memberships` (Active/Suspended/Revoked,
  closed reason codes, monotonic `AccessRevision`, role/company snapshot), immutable vessel-grant
  snapshot, `identity.Delegations` (validity window, approver, revoke reason),
  `identity.AccessRecoveries` (RECOVERY_REQUIRED) and command receipts; migration
  `20261118182535_AccountMemberships`, audited SaveChanges guard, closed audit projections.
- Config → persisted migration: `FederationSettings.Memberships` remains the grant source;
  `POST /api/v1/memberships/import` deterministically imports the caller tenant's operator
  entries; the persisted state only narrows (inactive ⇒ no actor, grant intersection, role and
  company must agree). Nothing is imported automatically and no access is widened.
- `MembershipSessionGate`: every authenticated request re-reads persisted state; suspended/
  revoked/conflicting membership or stale session access revision ⇒ anonymous (401), cookie
  deletion and `SessionRevalidation/membership_inactive` security event. OIDC login denies a
  non-Active membership and stamps `poseidon:arv`.
- Admin lifecycle commands (CSRF, Idempotency-Key, xmin CAS, SERIALIZABLE, tenant-scoped, no-store):
  import, suspend, resume, revoke, security-suspend, delegation create/revoke; reads list/detail
  (ETag)/delegations/current. Voluntary last-admin removal ⇒ 409 `last_admin`; forced
  `security-suspend` (separate `membership.security.suspend`) is not blocked and records
  RECOVERY_REQUIRED without a hidden admin. Delegation is maker-checker, bounded by the source's
  current grant, non-delegable admin permissions, ≤ 90 day technical window, server-time expiry,
  cascade revoke on suspend/revoke.
- `ICurrentMembershipResolver` published for PLAN-1511-5402 (effective received delegations are
  context only; not merged into generic permissions).
- S1 security contract 115/107/117 → 122/114/124; OpenAPI and `frontend/src/generated/api.d.ts`
  regenerated (additive only: 10 paths, 9 schemas); audit command vocabulary updated.
