## Decision rationale (CONDITIONAL release)

The task brief allowed RELEASE on CONDITIONAL with per-condition Master acknowledgements. 60.01 p952 is explicit that
RELEASE requires a CURRENT READY assessment, and no source defines a conditional-release policy. RELEASE on CONDITIONAL
is therefore refused (422 `departure_release_not_permitted`) and recorded here as an open expert gate. The Master's ISM
Code 5.2 overriding authority to refuse is preserved: HOLD and DENY are always recordable with a reason, in any state or mode.
