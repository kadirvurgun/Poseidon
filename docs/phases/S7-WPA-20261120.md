## Stable consumer interface (for WP-B tug assignment/readiness)

`backend/Poseidon.Api/CrewEligibilityContract.cs` — resolve from DI (scoped):

```csharp
public interface ICrewEligibilityEvaluator {
    Task<CrewEligibilityResult> EvaluateAssignmentAsync(TrustedActor actor, Guid vesselId, Guid assignmentId, CrewEligibilityWindow window, CancellationToken ct);
    Task<SafeManningEvaluation> EvaluateVesselAsync(TrustedActor actor, Guid vesselId, CrewEligibilityWindow window, CancellationToken ct);
}
public interface ICrewWorkRestSource { Task<CrewWorkRestFact> ReadAsync(Guid vesselId, Guid assignmentId, CrewEligibilityWindow window, CancellationToken ct); }
```

Result records live in `Poseidon.Domain` (`CrewEligibility.cs`): `CrewEligibilityResult(AssignmentId, PositionId, State, Reasons[], Gaps[], Qualifications[], Authority="ADVISORY_ONLY_NOT_A_DECISION")`, `CrewEligibilityReason(Code, Dimension, Severity, RequirementId?, SourceId?)`, `CrewEligibilityWindow(From, To)` (≤366 days). Semantics: advisory only, never a GO, release or Safe Manning decision. A caller without vessel scope plus `crew.read` and `crew.eligibility.read` (or `crew.safe_manning.read`) gets `REVIEW_REQUIRED / PROTECTED_CREW_SOURCE_ACCESS_REQUIRED`; the result never reveals whether the assignment exists. Results carry identifiers and codes only, no PII. The default `UnavailableCrewWorkRestSource` returns `UNKNOWN`, so **no evaluation can be ELIGIBLE until a 58.04 work/rest source is registered**.

## Human gates (never automated)

Credential verification assertion, competence sign-off and the Safe Manning decision each need an operator-provisioned `CrewAuthority` appointment, a Human membership and an active role context. No appointment, approved STCW catalog, work/rest source, vessel type/cargo context or MSMD qualification is provided by this package.

## Risks / next

- Every evaluation is REVIEW_REQUIRED until a 58.04 work/rest source exists; scoped requirements stay REVIEW_REQUIRED (vessel type/cargo context unknown).
- Credentials declared before this migration have no declaring actor and cannot be verified (conservative SoD).
- Credential requirement matching is an exact type-reference string match (no controlled lookup yet).
- Competence record SoD compares with the latest declarer only; an edit invalidates earlier sign-offs.
- The Safe Manning evaluation is recomputed inside the decision transaction (cost grows with crew size; bounded to 500 assignments).
