## Assessment of main before this package

Main already had three typed offline adapters (Crew watch_group, Tug plan window, Daily Noon/Deck/Engine) with encrypted IndexedDB queue, signed replay and durable per-actor receipts (OFFLINE-APPLICATION-01, S4-OFFLINE-FOUNDATION-20261104, S5 daily offline). The canonical `/api/v1/sync/operations` endpoint did not exist; the client had no way to learn which queued captures the server already held without re-signing/re-sending them, no per-resource ordering guard, and no visible "rejected key reuse" state.
