## Acceptance criteria

- **DEV023-AC-01** Every Today card carries `sourceRef` naming owner module (`REGULATORY|PMS|TUG`), record kind and id; id equals the card key/vessel.
- **DEV023-AC-02** `sourceRef.revision/savedAt` equal the Why lineage of the same read path; an absent regulatory draft has `null` revision and time (no invented value). For a TugJob the pair is the TugJob's own revision AND the TugJob's own save time (one record); a contributing draft plan is not represented in `sourceRef`, its lineage (plan revision, planned request revision) is shown in Why. Why `savedAt` uses the same job save time.
- **DEV023-AC-03** `nextAction` is `Review…` only when the actor passes the owning module write gate (Tug: `tug.plan.write` + vessel edit AND a current planning-policy scope `Planning(h).Scope(actor, vessel) != null`, identical to the plan write endpoints), else `View…`; the Why `nextAction` matches; Today performs no writes.
- **DEV023-AC-04** Priority and reason code remain server-derived codes; UI shows priority text + icon and the localized reason, never free text.
- **DEV023-AC-05** `viewState` is `Unavailable` when no owning source is readable, `Partial` when any is unavailable (currently always, because operational/safety/permit/evidence owners are not connected), `Empty`/`Ready` only with full coverage; UI says "not all clear" for Partial/Unavailable/Empty. Under any non-Ready state the total, attention and review counters carry a note: Partial/Unavailable → "partial sources: zero is not all clear"; Empty → its own "authorized empty result … not a safety clearance" note (61.03 paragraph:1061), never the partial note.
- **DEV023-AC-06** The client decoder rejects a card without an exact `sourceRef`, a mismatched owner/id, a non-positive revision, a draft revision without a draft, an unknown action and a server-promoted `viewState`.
- **DEV023-AC-07** Errors map deterministically (401 sign-in, 403 denied, 404 missing, 429 rate-limited, client contract-validation failure → validation message, HTTP 502/503/504/other/network → source unavailable), focus the alert, show no earlier data and allow retry (except 401).
- **DEV023-AC-08** Loading and offline are exposed as deterministic region states; offline start issues no request, is not `aria-busy` and exposes the offline status text.
- **DEV023-AC-09** Hidden module items leave no source ref, identifier or `PMS` owner code in the response; vessel grant removal returns 404 with no partial snapshot; tenant isolation unchanged.
