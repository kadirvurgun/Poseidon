## Actual contract and behavior

[ShipOperationsPolicy](../../backend/Poseidon.Domain/ShipOperationsPolicy.cs) exposes `ShipOpsFact {state,value}`, `ShipOpsFieldDefinition {key,type,required,options,readOnly,referenceUnavailable,sourceRow,unit,requiredWhen}`, kinds `Fuel|Port`, source/schema constants and `Schema`, `TryNormalize`, `TryInstant`, `ReadFields`, `Blockers`. The [source contract](../../contracts/ship-operations/ship-operations.draft.v1.json) carries all forty literal keys/rows/options and expansion semantics. API/backend and UI owners were sent these signatures before wiring.

- Every omitted mutable field becomes Missing/null. Explicit Unknown remains Unknown/null; Known is a nonempty bounded lexical string. JSON value/state members are required and unmapped fact members denied. Null facts, unknown keys, readonly fields and state/value inconsistencies fail. Text is not silently trimmed or converted; narrative newlines are retained. Web camelcase fact JSON is revalidated on read before derived source fields are added.
- Required source Yes becomes `required=true`. Source Conditional becomes `required=false, requiredWhen=SOURCE_CONDITIONAL_UNRESOLVED`, and always contributes an explicit conditional-review blocker. No guessed rule such as “Delivery automatically requires X” is invented. Partial drafts remain writable; missing required data, source lookup and human qualification gates remain explicit.
- Current voyage/port-call/port/supplier/tank/protest/evidence owning linkage is unavailable in this policy. Known is rejected for those fields, including plausible UUIDs. Unknown/Missing remain capturable. A recovered generic Evidence read API does not authorize a ShipOps evidence binding. Backend may later add actual scoped immutable linkage via a separate reviewed source change.
- Numbers retain signed/zero/large-precision lexical form, with technical length/grammar limits only. No binary/decimal rounding, computed ROB, emissions, financials, positivity, sulphur legal threshold or approved precision is inferred. `*_mt` fields expose the explicit `mt` label; `sulphur_pct` has the explicit source `%` label. Tank capacity, viscosity, density, cargo quantity and draught units remain null. All unit/range/signedness/precision approval remains review-required.
- `record_date`, `event_start`, `event_end` use a strict instant transport rule over the source Date/Time semantics: full ISO seconds plus explicit Z/offset, at most seven fractional digits. No browser-local timezone is assigned to a zone-less value. The original lexical offset survives; `TryInstant` supplies UTC `DateTimeOffset` for actual typed persistence/order. Unknown offset `-00:00`, invalid calendar/time, ambiguous zone-less and overprecision forms are rejected. Only two Known event endpoints can be ordered; temporal reversal fails by UTC instant. Unknown/Missing endpoint stays unknown and never becomes current time or a computed duration.
- Source options such as ROB, NONE, Other, Arrival or NOR remain exact declarations. READY, VERIFIED and FINAL source labels are not caller mutation permissions. Ordinary writes never establish those states.
