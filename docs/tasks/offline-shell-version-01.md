Authored behavior: Vite's actual writeBundle hook consumes only emitted index and exact public asset names. A deployment race or login HTML fails installation without replacing an existing valid shell. Update-race detail: predecessor public cache names are snapshotted before installation and persisted as bounded public-only metadata inside that build cache. Activation reads this persisted predecessor list, so a worker terminated while waiting retains the cleanup boundary. A newer build cache created after this install is preserved. The lifecycle regression simulates worker process recreation and a newer concurrently installed public cache.
