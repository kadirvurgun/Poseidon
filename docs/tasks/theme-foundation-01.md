Tercih şu anda yalnız tarayıcı profiline ait kozmetik seçimdir; tenant/account/person kaydı değildir. Anahtar `poseidon.appearance.v1`, kapalı değerler `{mode: light|dark|system, palette: emerald|ocean|graphite}`; credential/PII/auth/scope içermez. Tema değiştirmek server yetkisi veya audited business mutation üretmez. 52.02 hesabına sunucu tarafı tercih kaydı sonradan bağlanırsa kendi yetki/ETag/audit sözleşmesiyle yapılacak; bu paketle yapılmış sayılmaz.

Preset decode: Sera, Stone, Emerald, Cyan chart, Oxanium body, Geist heading, Phosphor icons, default radius, subtle/translucent menu. Bu pakette **renk/radius tokenları** uygulanır; mevcut Radix/Lucide/system-font bileşenleri korunur. Component style/base, icon ve font ailesini değiştirmek ayrı değerlendirme/migration, yerel font lisansı/barındırma ve kontrast/erişilebilirlik/regression kapısı ister. Yeni npm bağımlılığı veya remote font/registry runtime isteği eklenmez. Ocean/Graphite uygulamanın kendi ek paletleridir.

Ortak enterprise shell, temel form/tablo/surface ve bağlantı ekranı önceki pakette tokenlara geçirilmişti. **21.11.2026 tamamlama paketi (THEME-TOKEN-SWEEP-01):** `frontend/src` altında `design-system.css` dışında 32 CSS dosyası değişti: 17'sinde renk taşındı (product, technical, tug board/request, crew, vessel switcher, import, PMS, certificate, language selector, appearance controls, agents ops konsolu, styles.css vb.), kalan 15'i yalnız radius tokenlaması ve `DirectoryOverview.tsx`/`scope-chart-renderer.ts` içindeki ~220 sabit renk (hex, rgb(), `white`, `var(--x, #fallback)` fallback'leri) semantic tokenlara taşındı. Eşleme ilkesi: metin `--foreground`/`--muted-foreground`, bağlantı/eylem `--primary`, yüzey `--card`/`--muted`/`--accent`, kenar `--border`/`--input`, odak `--focus-ring`, bilgi notları `--info-*`, taslak/dikkat `--warning-*`, hata/blocked `--destructive`/`--danger-*`; seçili satırlar paletten türeyen yeni `--selection-surface`/`--selection-border`, gölge/backdrop moda duyarlı yeni `--shadow-color` ile `color-mix` kullanır. Yeşil/success tonu eklenmedi; UNKNOWN/REVIEW yeşil görünmez (Today kartında şerit ve rozet aynı anlamı taşır: `Attention` ve `Review` (REVIEW_REQUIRED) warning — Review kesikli şerit —, diğerleri neutral/muted; `todayPriorityTone` + `TodayPriorityTone.test.ts`. PMS alarm rozeti danger tonları. Durum/status hiçbir zaman `--primary`'ye eşlenmez; primary palet/marka rengidir ve emerald paletinde yeşildir). Tanımsız `--surface` fallback'i (#122a38) açık modda koyu select üretiyordu; `--card` ile düzeltildi. Agents ops konsolu sabit koyu temadan uygulama mod/paletine geçti; `.ops-ready` rozeti metni `--foreground` (zemin %10 primary karışımı) ile tüm yerleşik palet/modlarda ≥4.5:1 (`agents/ops-contrast.test.ts`).

**THEME-CHART-01:** Ürünün tek ECharts kullanımı (`ScopedDistribution` → `scope-chart-renderer`) artık seri rengi almaz; `theme/chart-theme.ts` render anında `--chart-1..5`, yüzey/tooltip ve korumalı semantic status tokenlarını (danger/warning/reviewRequired/info/unknown; success yok) `getComputedStyle` ile okur, root `class`/`data-palette`/builder `data-*` değişiminde (MutationObserver) aynı grafiği `setOption` ile yeniden boyar. Token çözülemezse grafik çizilmez, erişilebilir metin legend'ı kalır. Legend swatch'ları `var(--chart-N)` kullanır.

**THEME-PRESET-01 radius/font:** Domain CSS'lerindeki 6–14px `border-radius` değerleri `max(0px, calc(Npx + var(--radius-delta)))` oldu (`--radius-delta` preset 0.625rem'de 0): varsayılanda piksel değişmez, builder radius seçimi tüm yüzeylere ulaşır. Yazı tipi aileleri `--font-sans`/`--font-heading`/`--font-mono` tokenlarına bağlandı; değerleri mevcut çevrimdışı sistem yığınlarıdır. Snapshot Oxanium (body) / Geist (heading) / Phosphor (icon) / Sera style adlarını yalnız isim olarak kaydeder; font dosyası, sürüm veya lisans kaydı yoktur. Bu nedenle preset fontları **uygulanmadı** (uzak font isteği offline PWA'yı bozar; self-host için OFL font dosyası + lisans kaydı + görsel/kontrast kapısı gerekir), Phosphor ikon ve Sera component style geçişi de açık takiptir.

Kalan bilinçli literal renkler (allowlist, `hardcoded-colors.test.ts`): `design-system.css` (token tanımları), `theme/theme-tokens.ts` (builder palet ölçekleri ve kontrast matematiği), `theme/theme-builder.css` (theme-tokens'tan üretilir, eşitlik testle zorunlu). `src` dışı: `public/appearance-init.js` ilk-boyama `theme-color` hex'leri (CSS yüklenmeden önce çalışır, offline byte/hash envanterinde) ve `index.html` varsayılan `theme-color` meta değeri — bunlar tarama kapsamı dışında bırakıldı. Test fixture dosyaları (`*.test.ts(x)`) guard dışıdır. Bütün 196 ekranın görsel tema kabulü yoktur; gerçek browser görsel/kontrast (her mod × palet × builder), 320px ve klavye kapısı **DEFERRED**.
