## Contract

Registry entry (`MetricDefinition`): `id, version, ownerModule, label, unitCode, sourceProjectionId, aggregation, minCohort, freshnessRule, requiredPermissions, allowedActions (view only), scopes (TENANT_VISIBLE|VESSEL), basis, source`.

Endpoints (GET, `DirectoryRead`, `Cache-Control: no-store`, SecurityAudit `MetricCatalogRead` / `MetricScalarRead`, fail closed 503 when audit is unavailable):

- `GET /api/v1/metrics/definitions` (`ListMetricDefinitions`) — only definitions whose `requiredPermissions` the actor holds. No query parameters.
- `GET /api/v1/metrics/scalar?metricId=…[&vesselId=…]` (`GetMetricScalar`) — 400 unknown/duplicate keys or bad GUID; 404 unknown metric or vessel outside current scope (other tenant, ungranted, hidden ship/tug mode); 403 missing source permission.

`MetricScalarDto`: `metricId, definitionVersion, ownerModule, state (VALUE|SUPPRESSED|UNKNOWN|UNAVAILABLE), value (decimal string, only for VALUE), unitCode, quality (COMPLETE|PARTIAL|UNKNOWN), asOf, sourceProjectionId, sourceWatermark, scope {kind, vesselId, expectedSources, readSources, withheldSources, unreadableSources, notCollectedSources}, unknownCount, reasons[], basis, freshnessRule, source`.

Evaluation rules (`MetricScalarPolicy`):
1. Only records the actor may currently read: `TrustedActor.Scope` (tenant, vessel grant, ship/tug mode) and the source owner's own read rule (file-bound profile needs `file.read`; crew needs `crew.read`).
2. No visible source -> `UNKNOWN/NO_VISIBLE_SOURCE`; no source read -> `UNKNOWN` with the cause codes; never 0.
3. Unread sources have separate causes: `SOURCE_WITHHELD` (current access hides it; only these count in `withheldSources`), `SOURCE_UNREADABLE` (stored source cannot be decoded; `unreadableSources`), `SOURCE_NOT_COLLECTED` (no source declaration exists, 55.01 paragraph:263, no zero-fill paragraph:652; `notCollectedSources`). `expectedSources = readSources + withheldSources + unreadableSources + notCollectedSources`. Some unread -> value over read sources only, `PARTIAL` + `PARTIAL_SOURCE_COVERAGE` + cause codes; never presented as complete.
4. `minCohort > 1`: 0 < value < minCohort -> `SUPPRESSED/SMALL_GROUP`; any per-vessel component in (0, minCohort) -> `SUPPRESSED/COMPLEMENTARY_SUPPRESSION`; overlap differential `sum(per-vessel components) - distinct total` in (0, minCohort) -> `SUPPRESSED/COMPLEMENTARY_SUPPRESSION`. Value 0 is a real empty-set count.
5. > 1000 source vessels -> `UNAVAILABLE/QUERY_LIMIT_EXCEEDED`, never a truncated total.
6. Scope and source rows are read in one REPEATABLE READ snapshot; actor access is re-resolved after evaluation and after audit, a changed grant/permission returns 403.

Reference scalars:

| id | version | unit | source projection | minCohort | permissions |
|---|---|---|---|---|---|
| `onboarding.vessels.review_required` | 1 | vessel | `projection.compliance-onboarding.v1` (`ComplianceOnboardingPolicy`) | 1 | directory.read |
| `onboarding.required_fields.unknown` | 2 | field | `projection.compliance-onboarding.v1` | 1 | directory.read |
| `crew.assignments.declared_persons` | 2 | person | `projection.crew-assignment-declarations.v1` | 5 | directory.read, crew.read |

All are `DECLARED_UNVERIFIED`: no verification, readiness, presence or eligibility claim.

- `onboarding.required_fields.unknown` v2: a vessel with no profile declaration is `SOURCE_NOT_COLLECTED` (fleet -> PARTIAL, or UNKNOWN when no visible vessel has a profile), never a COMPLETE 0. `onboarding.vessels.review_required` still counts a missing profile as a vessel requiring review (a read fact, `PROFILE_MISSING`).
- `crew.assignments.declared_persons` v2: label "Persons with a declared crew assignment (any status or dates; not current crew)". It counts distinct persons with any declared assignment regardless of status or dates. **Today/Why (61.03, DEV-023/024) must not present it as current, onboard or eligible crew**; a current-crew metric needs its own definition once assignment status/date semantics are owned.

## Acceptance criteria

- P5501S-AC-01 Registry and `contracts/metrics.v1.json` are identical; ids unique, versions ≥ 1, view-only. (`MetricContractTests.Registry_*`)
- P5501S-AC-02 Missing/withheld sources give UNKNOWN or UNAVAILABLE with no value, never 0. (`Missing_or_withheld_sources_are_unknown_never_zero`)
- P5501S-AC-03 Real zero over read sources is VALUE 0 COMPLETE; partial coverage is PARTIAL. (`Real_zero_over_read_sources_*`)
- P5501S-AC-04 Small groups and complementary cells are SUPPRESSED with reason and no value. (`Small_group_*`, `Threshold_and_empty_group_*`)
- P5501S-AC-05 Inconsistent observations are rejected. (`Inconsistent_observations_are_rejected`)
- P5501S-AC-06 Catalog lists only permitted definitions; no-store; query spoofing rejected. (API `Metric_catalog_lists_only_definitions_the_actor_may_view`)

- P5501S-AC-08 Restricted actor gets a value over its granted vessel only; tenant isolation; removed grant 403. (API `Onboarding_scalars_count_only_current_scope_and_keep_tenant_isolation`)
- P5501S-AC-09 File-bound profile without `file.read` -> vessel UNKNOWN, fleet PARTIAL; private values not in body. (API `Withheld_file_bound_profile_*`)
- P5501S-AC-10 Crew scalar: SMALL_GROUP and COMPLEMENTARY suppression in real PG; other tenant's persons never counted; restricted actor own scope only. (API `Crew_scalar_*`)
- P5501S-AC-11 OpenAPI carries both operations and `MetricScalarDto` fields; generated frontend types; typed client fails closed on value-outside-VALUE / false COMPLETE. (`DiagnosticsTests.OpenApi_*`, `frontend/src/product/metrics-api.test.ts`)
- P5501S-AC-12 No-profile vessel is not-collected: vessel/fleet-without-profiles UNKNOWN, mixed fleet PARTIAL with `SOURCE_NOT_COLLECTED`; never COMPLETE 0. (`Not_collected_sources_*`, API `Vessel_without_profile_is_a_not_collected_source_never_zero_unknown_fields`)

- P5501S-AC-15 Audit write failure on the scalar endpoint -> 503 with no value/state/scope in the body. (API `Metric_scalar_fails_closed_without_value_when_its_audit_cannot_persist`)
