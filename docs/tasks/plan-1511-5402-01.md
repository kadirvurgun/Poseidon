## Acceptance criteria

- P5402-AC-01 Vessel-scoped exact action allows only the granted vessel.
- P5402-AC-02 Unknown, wildcard or unregistered action keys deny `ACTION_NOT_ENABLED`.
- P5402-AC-03 Purpose outside the action's closed list denies `PURPOSE_NOT_PERMITTED`, even with tenant-wide grants.
- P5402-AC-04 Tenant mismatch, wrong scope kind and missing/empty subject deny.
- P5402-AC-05 Write attribution required; read never yields write; `directory.write` never yields regulatory register authority; vessel-only grants never yield tenant register authority.
- P5402-AC-06 No catalog action derived from a legacy broad key contains a checker segment (approve/verify/release/publish/legal_review/activate/attest); `MIGRATION_REVIEW_REQUIRED` rows enable nothing.
- P5402-AC-07 Commit-time revalidation denies after revocation and on identity/tenant drift.
- P5402-AC-08 Dynamic SoD rejects self-approval and unknown makers.
- P5402-AC-09 Exhaustive equivalence: exact decision equals `CanEditVessel` / `CanWriteRegulatory` for 1,280 synthetic memberships; SoD helper is never wider than the legacy HumanReview independence rule.
- P5402-AC-10/12/13 Revocation inside the open write transaction (after the receipt INSERT) rolls back business row, history, EF audit and receipt for profile save, vessel update and register create; SecurityEvent records the denial.
- P5402-AC-11 Unrelated epoch change is recomputed and commits (no stale allow reuse, no blanket rejection).
- P5402-AC-14 Existing allow/deny behaviour of migrated endpoints unchanged (existing regression tests).

## Open items

- P5402-OPEN-01 Persisted role/grant/registry model (RoleRevision, RoleBinding, ScopeSet, GrantAuthority, DeploymentActivation) is not implemented; subject is still `FederationSettings` memberships.
- P5402-OPEN-02 Epoch is an in-process SHA-256 fingerprint of the current membership, not the persisted monotonic `authorizationEpoch` with outbox.
- P5402-OPEN-03 Active company boundary not enforced for migrated actions (legacy equality preserved); enforcing it is a narrowing that needs owner decision and test updates.
- P5402-OPEN-04 HTTP responses keep legacy `permission_denied`; 54.02 error envelope codes (`ACTION_NOT_ENABLED`, `ACCESS_CONTEXT_CHANGED` 409) and SecurityEvent code additions are deferred to the 58.03 profile work.
- P5402-OPEN-05 rowRule / fieldProfile / MASKED_READ and job/record scope; IAM_READ_V1 query catalog; IAM-3 mutation profile (idempotency 7d, 412/428).
- P5402-OPEN-06 Static SoD (incompatible role pairs), last-admin, grant ceiling and two-person grant flows.
- P5402-OPEN-07 Remaining endpoints in the mapping table.
