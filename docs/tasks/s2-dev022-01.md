## Acceptance criteria

- **DEV022-AC-01** The menu is built from the server-resolved role context: each lens equals the role's configured keys ∩ the items the current membership can open for the current vessel/mode.
- **DEV022-AC-02** A role mapping never adds a hidden item; mapped keys without permission (audit, maintenance) are absent from the lens response body.
- **DEV022-AC-03** Role selection in the UI is presentation only; no role, tenant or permission selector is accepted by any menu/lens/search endpoint.
- **DEV022-AC-04** Search matches an authorized destination by route key or by its TR/EN display label (Turkish-aware server folding, after the scope filter); a hidden destination does not match by key or label; the response is byte-identical to a query that matches nothing (no hasMore/count/label difference).
- **DEV022-AC-05** Vessel search is case-insensitive inside actor scope; a foreign-tenant vessel with the same code and an ungranted same-tenant vessel never match and give the same empty page.
- **DEV022-AC-06** `workspace/search` accepts only `q`/`offset`/`limit` once each and `workspace` accepts no query; anything else is 400, audited `Invalid`, without data.
- **DEV022-AC-07** Menu, lens and search projections are closed shapes without count/total/hidden aggregates; the browser rejects extra members.
- **DEV022-AC-08** Lens denial for foreign, ungranted and missing vessels is the same 404 and is audited with `resourceId`.
- **DEV022-AC-09** Search results show localized destination labels, never raw route keys.
- **DEV022-AC-10** Sidebar menu filter searches only authorized items by localized label (TR I/İ/ı/i, diacritics), opens every matching group, never names/counts a hidden entry, and is keyboard operable (ArrowDown to results, Escape clears before closing the drawer, clear button returns focus); TR/EN + 17 catalogs.
- **DEV022-AC-11** A direct URL to the audit screen without audit permission shows the generic heading and denial, not the hidden screen name; the server denial is unchanged.
